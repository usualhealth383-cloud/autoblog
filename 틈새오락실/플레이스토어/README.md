# 틈새 오락실 — 플레이스토어(TWA) 준비물

| 파일 | 용도 | 상태 |
|---|---|---|
| `icon-512.png` | 앱 아이콘 512×512 | ✅ (사이트 아이콘과 같음) |
| `feature-1024x500.png` | 그래픽 이미지(스토어 맨 위 띠) | ✅ |
| `screens/1~6.png` | 휴대전화 스크린샷 1080×1920 6장 (홈 · 게임 목록 · 사과 10 · 떡꼬치 정리 · 윷놀이 · 성 지키기) | ✅ |
| `twa-manifest.json` | Bubblewrap 포장 설정 | ✅ 초안 |
| `assetlinks.template.json` | 앱 ↔ breakpocket.com 연결 증명 | ⬜ 지문(SHA-256)은 Play Console 「앱 무결성 → 앱 서명」에서 받아 채운 뒤 사이트 `/.well-known/assetlinks.json` 에 올림(사이트에 `.nojekyll` 있어 그대로 나감) |

## 순서
1. D-U-N-S 번호 → Play Console 기업(메디나눔) 계정 25달러 결제(현욱님)
2. 앱 만들기: 이름 「틈새 오락실」, 기본 언어 한국어, 게임, 무료
3. 포장: `npx @bubblewrap/cli init --manifest https://breakpocket.com/manifest.webmanifest` → `twa-manifest.json` 값으로 맞춘 뒤 `bubblewrap build` → `.aab` 업로드(서명 키는 Play 앱 서명 사용)
4. Play Console의 앱 서명 SHA-256 → `assetlinks.json` 채워 사이트에 배포 → 주소창 없이 열리는지 확인
5. 스토어 등록정보(아래 문구) · 콘텐츠 등급 설문(IARC) · 데이터 보안 설문 · 광고 없음 · 개인정보처리방침 주소
6. 비공개 테스트 → 프로덕션

## 설문 답 메모
- 콘텐츠 등급(IARC): 폭력 = 만화풍 가벼운 충돌(격투·포탄), 도박 = 없음(실제 돈 없음), 음주 = 모임 게임 「모두의 술자리」에 음주 언급 있음(만 19세 이상 안내), 사용자 소통 = 닉네임 순위·실시간 대결(채팅 없음), 위치 공유 = 없음
- 데이터 보안: 수집 = 닉네임(선택)·점수·나라(선택)·로그인 시 이메일. 판매·광고 공유 없음. 전송 암호화(HTTPS). 삭제 요청 가능.
