## ② 카카오 로그인 켜기 — 약 15분 · 사업자(비즈앱) 없어도 됨
1. https://developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가(앱 이름: 틈새 오락실, 회사명: 메디나눔)
2. 제품 설정 → 카카오 로그인 → **활성화 ON**
3. Redirect URI 에 `https://bbwftbmqrfcnwydlqevm.supabase.co/auth/v1/callback` 등록
4. 동의항목: **닉네임 · 프로필 사진만**(이메일은 비즈앱 전용이라 켜지 않음)
5. 앱 설정 → 플랫폼 → Web 사이트 도메인 `https://breakpocket.com`
6. 앱 키의 **REST API 키**, 보안 → **Client Secret 코드 생성·사용함**
7. Supabase → Authentication → Sign In / Providers → **Kakao**: 켜기 · Client ID = REST API 키 · Secret = Client Secret · **「Allow users without an email」 켜기** → 저장
8. 끝: 앱 로그인 창에 「카카오로 시작하기」 단추가 저절로 생김(앱은 닉네임·사진만 요청하도록 이미 바뀜)
- 근거: Supabase 카카오 안내(이메일 없이 쓰려면 account_email 빼고 「Allow users without an email」) https://supabase.com/docs/guides/auth/social-login/auth-kakao

## ③ 통계 SQL 한 번 실행 — 1분
- Supabase → SQL Editor → 이 폴더의 `hanpan_demo_stats.sql` 내용 붙여 넣고 Run
- 그 뒤: 관리자 화면(내 계정 → 👑 관리자 화면) 맨 아래 「연령대 · 성별 · 나라별 게임 이용」에서 7·30·90일 표
- 실행 전에도 앱은 정상(꼬리표만 안 붙음). 실행 뒤부터 쌓임 — **지난 기록에는 꼬리표가 없음**

## 무엇이 모이나 (개인정보)
- 회원이 **선택**으로 알려 준 연령대(10대~70대 이상) · 성별 · 나라 코드만. 이름 · 생일 · 전화번호는 묻지 않음.
- 게임 이용 기록에 이 세 꼬리표만 붙고, 화면에서는 **묶음 숫자**로만 봄(개인 단위 표 없음).
- 개인정보 처리방침 · 가입 안내 문구를 「연령대 · 성별 · 나라별 게임 · 검사 묶음 통계」로 고침(v389).
