## 4. JSON 읽는 법
- `kind` 는 **지금 문항**의 유형, `think` 는 지금 문항을 풀 때 할 생각. rewrite 문항은 `draft.kind`·`draft.think` 에 바뀐 뒤의 유형·생각을 적었다.
- `draft` 칸: `stem`(발문) · `choices`(선지, 정답 위치 그대로) · `source`(합답형 보기 ㄱㄴㄷ — 정답 조합 그대로) · `data`(자료 상자) · `explain`(해설) · `wrong`(바로알기). 적지 않은 칸은 그대로 둔다.
- recall-only 문항에도 선지·바로알기 초안을 달았다 — 빈칸 떠올리기 칸에 두더라도 X1(문법으로 풀림)·X8(다른 개념 해설)은 고쳐야 하기 때문이다. 손으로 고른 선지는 `extract_bank.py` 의 `AUTO_CHOICES` 에 넣는 꼴이 맞다(1303-b3-㉠ 처럼).
- 사고력 문제 수를 셀 때 recall-only 55문항과 체크 78문항은 뺀다.
