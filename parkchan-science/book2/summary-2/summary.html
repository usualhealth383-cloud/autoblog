II. 환경과 에너지대단원 마무리 — 소단원 핵심 카드
01생태계의 구성과 상호 관계80쪽
  • 위계: 개체 → 개체군(같은 종) → 군집(여러 종) → 생태계(+환경)
  • 3배역: 생산자·소비자·분해자(순환의 완성) / 비생물 5요인
  • 화살표는 쌍방향 — 적응(환경→생물) vs 개조(생물→환경)
여우 귀 = 온도층상 구조 = 빛가시 = 물
02생태계 평형93쪽
  • 그물 복잡 = 안정 / 피라미드 위로 갈수록 ↓ (에너지가 새서)
  • 회복 공식: 급증 → 먹이 ↓ + 천적 ▲ → 감소 → 회복
  • 복원력엔 한계 — 파괴 4적: 서식지·남획·외래종·오염
옐로스톤 늑대생태 통로협력적 소통
03지구온난화와 기후변화106쪽
  • 사슬: 연소 → 온실 기체 ↑ → 적외선 더 붙잡힘 → 기온 ↑
  • 해수면 = 융해 + 열팽창 / 킬링 곡선: 톱니 = 계절, 추세 = 인류
  • 엘니뇨 = 무역풍 약화 + 동태평양 수온 ↑ / 사막화 → 황사
280→420 ppm완화 + 적응1.5 ℃
04태양 에너지와 에너지 전환121쪽
  • 태양: 수소 4 → 헬륨 1 + 에너지(질량 감소분, 중심부에서)
  • 위도 차 → 대기·해수 순환 / 광합성(빛→화학) → 화석 연료 = 옛 태양
  • 족보 판정: 거의 모두 태양 — 예외는 지열·조력뿐
반사 30 흡수 70밥상의 족보에너지 보존
05발전과 에너지의 효율적 이용134쪽
  • 전자기 유도: 상대 운동 → 전류 — 발전기(운동→전기)
  • 공통 문법: 터빈 → 발전기 / 화력 −CO₂ · 핵 −폐기물 (바꿔치기 금지)
  • 효율 = 유용 ÷ 공급 ×100 — 효율 ↑ = 연료 ↓ = CO₂ ↓
백열등 ~5 %신재생 = 지금의 태양
