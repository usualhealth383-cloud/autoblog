이제 데이터는 석유에 비유될 만큼 중요한 자원이 되었다. 검색 기록과 이동 경로가 서비스를 개선하고, 축적된 진료 데이터가 새 치료법 연구의 바탕이 된다. 물론 그림자도 있다 — 개인 정보 유출, ㉡(디지털 기술 접근성의 차이가 만드는 정보의 불평등), 가짜 정보의 확산. 기술을 누리는 것만큼 데이터를 다루는 ㉢도 커졌다는 것, 그것이 디지털 문명이 우리 세대에게 남긴 숙제다.

이 소단원을 한 장으로 정리한다. 변화 → 측정 → 분석 → 정보(일기예보·심전도·지진 경보). 아날로그(연속) vs 디지털(0과 1), 변환 = 표본화 + 수치화. 디지털의 힘 = 잡음에 강함 · 저장·전송·가공 자유 · 복사해도 불변. 정보 통신 문명 = 스마트폰·원격 의료·재난 경보 — 데이터는 자원, 책임은 숙제. 측정 장치가 달린 사물들이 서로 데이터를 주고받는 사물인터넷(IoT)은 통합과학2에서 다시 만난다.

사물인터넷(IoT)측정 장치가 달린 사물들이 서로 데이터를 주고받는 연결망 — 통합과학2에서 다시 만난다.
디지털 격차디지털 기술 접근성의 차이가 만드는 정보의 불평등 — 기술 문명의 그림자다.
데이터 = 자원검색 기록·이동 경로·진료 데이터가 서비스 개선과 새 치료법 연구의 바탕이 된다. 다루는 책임이 함께 커진다.
✗ 오해 디지털 문명에는 개인 정보 유출 같은 그림자가 없다.
✓ 진실 유출 · 격차 · 가짜 정보가 숙제다. 누리는 만큼 책임도 커졌다.
✗ 오해 의료 영상은 촬영한 병원에서만 볼 수 있다.
✓ 진실 디지털화된 영상은 어디서든 열람·전송되어 원격 판독과 협진이 된다.

1아날로그 신호와 디지털 신호에 대한 설명으로 옳은 것은?오개념

  1. ① 디지털 정보는 여러 번 복사해도 내용이 변하지 않는다.
  2. ② 수은 온도계의 눈금은 불연속적인 값을 나타내는 디지털 신호이다.
  3. ③ 자연의 신호는 원래 0과 1로 이루어진 디지털 신호이다.
  4. ④ 디지털 신호는 아날로그 신호보다 잡음의 영향을 크게 받는다.
  5. ⑤ 표본을 촘촘히 뽑을수록 데이터의 용량은 작아진다.

2다음은 어떤 소리를 디지털로 변환한 자료다.자료 해석

아날로그 신호를 0.001초 간격으로 표본화하고 0~7의 8단계로 수치화했더니, 뽑힌 값은 차례로 3, 5, 7, 6, 4, 2, 1, 3이었다.

이 자료에 대한 설명으로 가장 적절한 것은?

  1. ① 표본 사이의 정보는 영원히 사라져 복원할 방법이 없다.
  2. ② 표본 간격을 0.0005초로 줄이면 데이터의 용량은 절반이 된다.
  3. ③ 8단계는 이진수 세 자리로 적을 수 있으므로 3, 5, 7은 011, 101, 111로 저장된다.
  4. ④ 값을 반올림해 기록하는 과정을 표본화라 한다.
  5. ⑤ 단계를 16단계로 늘리면 원본과의 차이가 더 커진다.

3카세트테이프는 복사할수록 잡음이 쌓이지만 디지털 음원은 복사해도 변하지 않는 까닭을 '0과 1'과 '잡음'을 포함하여 서술하시오.서술형
