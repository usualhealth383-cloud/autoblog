II. 물질과 규칙성대단원 마무리 — 소단원 핵심 카드
01우주의 시작과 원소의 탄생63쪽
  • 빅뱅 후 식는 순서대로: 기본 입자 → 양성자·중성자 → 핵(3분) → 원자(38만 년)
  • 빅뱅의 2대 증거: 우주 배경 복사 · 수소:헬륨 질량비 약 3:1
  • 스펙트럼 3종 — 연속/방출(밝은 선)/흡수(검은 선), 선의 위치 = 원소의 지문
02별에서 만들어지는 원소75쪽
  • 별 내부 핵융합은 철까지 — 금·우라늄은 초신성 폭발 등 격변에서
  • 초신성이 흩뿌린 원소 → 태양계 성운 → 태양·지구·생명
  • 몸속 탄소·산소·철의 고향은 별 — 우리는 별의 후손
03원소의 주기성과 화학 결합88쪽
  • 같은 족 = 닮은 성질 — 원자가 전자 수가 같아서 (1족 알칼리 금속, 17족 할로젠)
  • 결합의 이유: 비활성 기체형 전자 배치 — 이온 결합(주고받기) / 공유 결합(나눠 갖기)
  • 이온 결합 물질의 전기 전도성: 고체 ×, 수용액·액체 ○
04지각과 생명체 물질의 규칙성103쪽
  • 공통 원리 = 단위체의 결합: 규산염 사면체 → 광물 / 아미노산 → 단백질 / 뉴클레오타이드 → DNA
  • 지각 최다 원소는 산소(규소가 아니다!) · 사면체 = 규소 1 + 산소 4
  • 단백질은 아미노산 순서가, DNA는 염기 순서가 정보다
05물질의 전기적 성질과 신소재116쪽
  • 전기 전도성으로 셋: 도체(잘 통함) · 부도체(안 통함) · 반도체(조건에 따라) — 반도체가 전자 문명의 심장
  • 신소재: 그래핀(탄소 한 층 — 투명·강함·잘 통함) 등, 물질의 전기적 성질이 곧 기술의 재료다
시험 전 마지막 점검 — 3분 OX
  1. 1헬륨 원자핵은 빅뱅 후 약 38만 년에 만들어졌다. ( O , X )
  2. 2금은 보통의 별 내부 핵융합으로 만들어진다. ( O , X )
  3. 3같은 족 원소의 화학적 성질이 닮은 것은 원자가 전자 수가 같기 때문이다. ( O , X )
  4. 4지각에 가장 많은 원소는 규소다. ( O , X )
  5. 5고체 염화 나트륨은 전기가 잘 통한다. ( O , X )
정답 1 X (약 3분 — 38만 년은 원자) 2 X (초신성 등 격변) 3 O 4 X (산소) 5 X (수용액·액체 상태여야) — 틀린 번호의 소단원으로!
