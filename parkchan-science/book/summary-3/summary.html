III. 시스템과 상호작용대단원 마무리 — 소단원 핵심 카드
01지구시스템131쪽
  • 다섯 권역(기권·수권·지권·생물권·외권)이 물질 순환·에너지 흐름으로 연결
  • 에너지원 셋: 태양 에너지(최대) · 지구 내부 에너지 · 조력
02판구조론145쪽
  • 판 경계 3종: 발산(새 지각) · 수렴(소멸, 밀도 큰 해양판 침강) · 보존(변환 단층)
  • 지진·화산의 분포 = 판 경계의 지도 — 원동력은 맨틀 대류
03중력과 운동158쪽
  • 질량(불변) vs 무게(중력의 크기, 달에서 1/6) — 방향은 지구 중심 쪽
  • 자유 낙하는 질량 무관 · 수평 투사 = 수평 등속 + 연직 낙하(동시 착지)
  • 위성 = 무중력이 아니라 계속 낙하 중
04운동량과 충격량171쪽
  • 충격량 = F × t = 운동량 변화량 — F-t 그래프의 넓이
  • 한 등식, 두 용법: 보호는 시간↑ → 힘↓ / 발사는 시간·힘↑ → 충격량↑
05생명 시스템과 화학 반응184쪽
  • 물질대사는 체온에서, 단계적으로, 효소와 함께 — 연소와의 3대 차이
  • 효소 = 활성화 에너지 ↓ 생체 촉매, 단백질이라 열에 약함(감자 실험)
  • 세포막: 작은 분자는 직접 확산, 큰 분자는 막단백질 통로
06유전자에서 단백질까지197쪽
  • 정보의 한 방향 흐름: DNA →(전사)→ RNA →(번역)→ 단백질 → 형질
  • 전사는 핵 안(T 대신 U), 번역은 리보솜 — 장소 바꿔치기가 최다 함정
  • 염기 수 ÷ 3 = 아미노산 수 · 염기 하나가 형질을 바꾼다
시험 전 마지막 점검 — 3분 OX
  1. 1지진과 화산은 판의 안쪽 한가운데에 고르게 분포한다. ( O , X )
  2. 2달에 가면 질량이 1/6로 줄어든다. ( O , X )
  3. 3에어백은 충돌 시간을 늘려 사람이 받는 힘을 줄인다. ( O , X )
  4. 4세포 호흡은 포도당을 합성하는 동화 작용이다. ( O , X )
  5. 5전사는 핵 안에서, 번역은 리보솜에서 일어난다. ( O , X )
정답 1 X (판 경계에 몰린다) 2 X (무게만 1/6, 질량 불변) 3 O 4 X (분해 — 이화 작용) 5 O — 틀린 번호의 소단원으로!
