## 2. 데이터 안전 섹션

앱이 실제로 다루는 것만 적었습니다. **수집하지 않는 것**: 위치, 재무 정보, 건강·피트니스,
사진·동영상, 음성, 주소록, 기기의 캘린더, 파일, 광고 ID, 기기 식별자.

| 데이터 | 수집 | 공유 | 필수 | 목적 |
|---|---|---|---|---|
| 이름 | 예 | 아니요 | 필수 | 앱 기능(계정·학원 명단 대조) |
| 이메일 주소 | 예 | 아니요 | 필수 | 계정 관리 |
| 전화번호 | 예 | 아니요 | 선택 | 앱 기능(학원 공지 문자) |
| 사용자 ID | 예 | 아니요 | 필수 | 앱 기능(계정 식별) |
| 기타 사용자 제작 콘텐츠 | 예 | 아니요 | 선택 | 앱 기능(커뮤니티 글·댓글) |
| 앱 내 활동(기타 작업) | 예 | 아니요 | 선택 | 앱 기능·분석(진도·정답률·출석·일정) |

- 전송 중 암호화: **예** (전 구간 HTTPS)
- 데이터 삭제 요청: **예** (앱 내 `내 정보 › 계정 삭제`, 그리고 위 계정 삭제 URL)
- 제3자 공유: **없음**. Supabase 는 처리 위탁(호스팅)이며 공유가 아닙니다.
- 앱 내 검색어: 기기 안에서 목록을 거르는 데만 쓰고 서버로 보내지 않으므로 **수집하지 않음**.

## 3. 사용자 제작 콘텐츠(UGC) 정책 대응

플레이는 UGC 앱에 신고·차단 기능과 조정 체계를 요구합니다. 심사 질문에 이렇게 답하면 됩니다.

| 요구 | 우리 앱의 답 | 위치 |
|---|---|---|
| 콘텐츠 신고 | 모든 글과 댓글에 신고 단추 | 이야기 › 글 상세 |
| 사용자 차단 | 글·댓글에서 차단, 내 정보에서 해제 | 이야기 › 글 상세 / 내 정보 › 차단한 사용자 |
| 자동 조치 | 신고 3건이면 자동으로 가림 | `REPORT_HIDE = 3` |
| 사람이 하는 조정 | 원장 › 이야기 에 신고가 모이고, **영업일 1일 1회 이상** 확인 | 약관 제8조의2 ④ |
| 정책 게시 | 이용약관 제8조의2·제8조의3, 이야기 화면 하단 규칙 | 앱 안·웹 |
| 금지 게시물 안내 | 개인정보·타인 저작물 원문·비방·유해물·광고·시험 유출 | 글쓰기 화면 |

만 13세 미만을 포함하면 **패밀리 정책**이 적용되어 요건이 크게 늘어납니다. 우리 앱은 가입 시

학원의 실제 수강생 연령을 보고 정해야 합니다. 초등부가 없다면 **13세 이상**으로 신고하는 것이 맞습니다.
