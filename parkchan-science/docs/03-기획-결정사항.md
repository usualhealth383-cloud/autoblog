# 박찬 과학 — 기획 결정·검토 사항

## 제품 개요

- 대상: 중3·고1 (통합과학1·2), 2028 수능 체제(통합과학 공통 응시) 세대.
- 구성: ① 정식 도서(400~600p, 통합과학1·2), ② 앱(1일 1문제 / 단락별 핵심 개념 / 커뮤니티 / 모의고사+상세 해설), ③ 콘텐츠 DB가 도서·앱의 단일 원천(single source of truth).

## 콘텐츠 전략

- 성취기준(31개)을 뼈대로 오리지널 본문·그림·문항 집필. 시중 교재는 디자인 문법·구성 관행의 벤치마크로만 활용(문장·그림·문항 복제 금지).
- 집필 시 범위 한정 지침 준수 (예: 산·염기는 아레니우스 정의만, 산화수 미취급).

## 캡처 방지 — 기술적 사실

| 플랫폼 | 캡처 차단 가능 여부 |
|---|---|
| Android 네이티브 | **가능** — FLAG_SECURE로 스크린샷·화면녹화 완전 차단 (Flutter/RN에서도 설정 가능) |
| iOS | **차단 불가(OS 정책)** — 스크린샷 발생 감지(알림)만 공식 지원. 차단 트릭은 비공식·심사 리스크 |
| 웹(브라우저) | 불가 |

→ 결론: **네이티브(또는 Flutter) 앱 필수**. Android는 완전 차단, iOS는 감지 + 대응(경고, 반복 시 이용 제한) + **화면에 사용자별 워터마크(이름/전화번호 일부)** 상시 표시로 유출 억지. 카메라로 화면을 찍는 것은 어떤 기술로도 못 막으므로 워터마크가 실질적 억지책.

## 결제

- 원생: QR 대신 **계정 승인 방식** — 가입 시 학원 코드 입력 → 관리자 대시보드에서 명단 대조 승인, 퇴원 시 원클릭 해제. 캡처 유출 원천 차단 + 원생별 학습 현황 확보.
- 일반 사용자: 인앱결제(IAP). 부모 결제 지원 방식:
  1. **결제 요청 링크**: 학생이 앱에서 "보호자에게 결제 요청" → 부모 휴대폰으로 링크 전송 → 부모가 웹에서 카드/간편결제(토스페이먼츠·카카오페이 등) — 앱 심사 정책 확인 필요(한국은 인앱결제강제금지법으로 제3자 결제 허용, 수수료 구조 비교할 것)
  2. Google 패밀리 결제 승인 / Apple 가족 공유 '구입 요청' 기능 안내
- 가격 준거: 경쟁 앱 구독 월 1.8~2만원대.

## 기출 문제 수록 (실전 문제 코너)

시그널 등 시중 교재는 '실전 문제'에 실제 학평 기출("2023학년도 고1 11월 학력평가 19번" 식 출처 표기)을 수록한다. 우리도 같은 코너를 만들되:

- **학평(교육청)·수능/모평(평가원) 문항은 저작물** — 상업 출판·유료 앱 수록에는 **저작권 이용 허락 신청이 필요** (시도교육청/평가원의 기출문제 이용 허락 절차, 통상 유료). 시중 출판사들도 이 라이선스를 받고 수록하는 것.
- **원칙 확정: '선수록 후허락'과 '변형 수록'은 하지 않는다.** 사후 허락은 이전 침해를 소급 치유하지 못하고, 변형해도 원본의 창작적 표현(자료 구성·보기 문장)이 남으면 침해다. 무단 수록 이력은 이후 허락 심사에도 불리하다.
- 합법 정공법: 저작권은 표현만 보호하고 아이디어·사실·문항 형식은 보호하지 않는다 → **기출 분석표**(연도·문항·출제 포인트·자료 유형을 사실 수준으로 기록) → **자료·발문·보기를 완전 신작** (사설 모의고사 업계 방식).
- 단기 전략: 허락 전까지는 **자체 제작 '학평 스타일' 문항**으로 실전 코너 운영 (현재 STEP 3 방식). 각 소단원 집필 시 기출 분석표를 먼저 작성해 신작 문항이 출제 경향을 정조준하게 한다.
- 중기 전략: 원장 명의로 교육청·평가원 기출 이용 허락 신청 → 승인 후 기출 + 출처 표기로 교체/병행. 2028 수능 예시문항(평가원 공개)의 수록 조건도 함께 확인.
