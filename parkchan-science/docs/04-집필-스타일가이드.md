# 박찬 과학 집필 스타일 가이드 v1

## 책 체계

- **본책 (지금 만드는 것)**: 통합과학1·2 정규 교재. 이 책 한 권으로 공부가 완결되도록 **정보 누락 없이** 서술.
- **별책 (추후 의뢰 예정)**: 핵심 요약본. 본책의 알짜 정리·이것만은 코너가 별책의 원천 데이터가 된다 (DB 단일 원천 원칙).

## 문체 원칙 — "풀어 말하듯"

1. **본문은 강의하듯 흐르는 서술형으로 쓴다.** 끊어 치는 개조식(–, · 나열)은 본문에서 최소화한다.
   - ❌ "기본 입자 생성 — 빅뱅 직후, 쿼크와 전자 등이 생겼다."
   - ⭕ "빅뱅 직후의 우주에는 먼저 쿼크와 전자 같은 기본 입자들이 생겨났다. 우주가 조금 더 식자 쿼크 세 개가 뭉쳐 양성자와 중성자가 되었고…"
2. 개조식은 **알짜 정리 / 이것만은 / 날개단**에서만 쓴다 (요약 코너의 역할).
3. 새 용어는 처음 등장할 때 반드시 풀어 정의하고, 재등장 시 "개념 n" 참조를 단다.
4. 문장은 짧게 끊더라도 문장 사이 연결어(그래서, 그런데, 즉)로 흐름을 잇는다 — 눈으로 읽어도 강의처럼 들리게.
5. 비유·질문을 아끼지 않는다 ("안개 낀 우주", "빛의 바코드"). 단, 유치한 톤 금지.

## 강의 사용성 (원장님 60대 — 수업 도구로서의 책)

- 페이지를 편 순간 **오늘 가르칠 것이 한눈에** 보여야 한다: 섹션 번호 크게, 그림은 본문과 같은 페이지에, 페이지 넘겨야 이어지는 설명 금지(소단원 내 개념 하나 = 한 페이지 원칙).
- 그림에는 항상 **읽는 순서**가 있게 (좌→우, 번호, 화살표) — 칠판에 그대로 옮겨 그릴 수 있는 수준의 단순함.
- 바로바로 체크는 수업 중 즉석 발문용, 박찬쌤 한마디는 수업 멘트 대본을 겸한다 (원장님 어록으로 교체 가능).
- 글자 크기 하한: 본문 9.5pt, 날개단 8pt 미만 금지.

## 완결성 (정보 누락 방지) — 이 책 하나로 커버

- 근거 원천 우선순위: ① 교육부 고시 성취기준·내용 체계(별책9) ② 성취기준 해설의 범위 한정 ③ 교과서 공통 내용 요소.
- 챕터마다 4단계 검증(커버리지 보드): 성취기준 대조 → 서술어별 문항 존재 → 교과서 5종 목차 교차 비교 → 원장 검수.
- **시험에 나오는데 본문에 없는 내용 = 결함**으로 취급. 문항의 모든 정답 근거는 반드시 본문에 존재해야 한다 (역추적 검사).

## 그림 품질 기준 (2026-09-01 원장 피드백 — "교재의 퀄리티는 그림에도 있다")

모든 개념 그림은 아래 5가지를 통과해야 한다. 하나라도 아니면 다시 그린다:

1. **입체 대상은 입체로** — 실물이 구·입체인 대상(원자 모형의 볼-스틱, 별, 행성, 분자)은
   radialGradient 음영으로 입체감을 준다. 평면 삼각형+동그라미로 사면체를 그리지 않는다.
   단, 관례가 평면인 도식(전자껍질 모형, 스펙트럼 띠, 주기율표)은 평면 유지.
2. **다단계 그림은 단계 번호** — 과정 그림엔 ①②③ 배지와 진행 화살표. 읽는 순서가 그림 안에 있어야 한다.
3. **개체의 정체성 유지** — 같은 대상이 여러 단계에 걸쳐 나오면 색·라벨을 유지해
   "같은 것이 변해 간다"가 보이게 한다 (예: 아미노산 구슬이 사슬→접힘까지 같은 색 순서).
4. **기능·성질은 구체 장면으로** — 추상 블롭 금지. 효소는 기질과 맞물리는 홈으로,
   전도성은 켜진 전구(글로우)로, '방출'은 방향 있는 화살표로 그린다.
5. **참조 무결성** — url(#marker/gradient)는 반드시 문서 안에 정의. qa_check R5가 자동 검사한다
   (누락 시 화살촉·음영이 조용히 사라지는 사고 방지).

## 그림 품질 3원칙 (2026-09-02 원장 피드백 반영 — 재발 방지 규정)

1. **생물 실루엣 식별 테스트**: 라벨을 가리고도 무슨 생물인지 알 수 있어야 한다.
   해부학적 특징 최소 2개를 반드시 그린다(공룡=긴 목+꼬리+다리, 매머드=엄니+코, 삼엽충=머리방패+마디+3엽).
   '선 몇 개짜리 뭉갠 형태' 금지. 채운(filled) 실루엣 우선. 확대 렌더(180dpi+)로 식별성 검수 후 통과.
2. **그래프의 y축은 정량 근거를 가진다**: 곡선의 높이·낙폭·기울기는 실제 데이터 비례를 반영한다
   (예: 다양성 계단 — 고생대 말 낙폭이 최대(과 수 약 절반), 중생대 말은 그보다 작게, 신생대가 역대 최고).
   비교 기준선(점선)과 낙폭 주석으로 '높이 차이 자체가 정보'임을 드러낸다. 임의의 예쁜 곡선 금지.
3. **라벨 밀집 금지**: 실제 비례 때문에 라벨이 한쪽에 몰리면 — 라벨을 우겨넣지 말고
   '돋보기 확대 띠'(구간 확대 2단 구성)로 펼친다. 밀집이 곧 교육 포인트가 되도록 설계한다.

## 강의 판본 규격 (2026-09-02 원장 선택: 시안 A '판서 흐름형' 확정)

- 세로 국배판 동일. 글자 본책의 약 1.4배(본문 11.8pt), 날개·배지·바로바로 체크 전부 제거.
- 페이지 구조: 이야기 제목 → **뼈대 3걸음(①②③)** → 큰 그림 1장 → 강의체 본문 → "칠판에 이 한 줄".
- '대본 티' 금지: 낭독 지시·손글씨 인용 없이, 강의체 문장 그 자체로. (시안 B 탈락 사유)
- **빈칸 시스템**: 뼈대·본문에 ㉠㉡㉢ 빈칸을 뚫고, 정답은 페이지 하단에 작게 180° 회전으로.
- 그림은 장면형(하늘 그라데이션·번호 칩 ①②③·비교 카드)으로 본책보다 크게. **좋아진 그림은 본책에도 역반영**(2203 그림 1 교체 완료가 첫 사례).
- 밀도 규격(3차 확정): 페이지 = 뼈대 3걸음 + 그림 1장 + **본문 3문단**(용어·출처까지) + **오해✗→진실✓ 카드 2개** + (자료형이면) **핵심 숫자 칩 3개** + 칠판 한 줄 + 회전 정답. 본문 11.2pt/**행간 1.88·문단 간 5.5mm·좌우 여백 19mm** 아래로는 줄이지 않는다. 지면이 모자라면 ① 라벨·출처류 정보를 그림 속으로 흡수(글→이미지) ② 문단 통합 ③ 그림 축소 순으로 해결 — 행간·여백 축소는 금지. 페이지당 본문은 최대 2문단: 셋째 문단이 필요해지면 내용을 카드·그림으로 옮긴다.

## 강의용 교재 최종 규격 (2026-09-02 4차 확정 — 출간용)

- **개념 1개 = 2쪽 펼침**: A면(제목 + 뼈대 3걸음 + 큰 그림 + 도입·원리 문단) / B면(심화 문단 + 용어 정리표 + 오해✗→진실✓ 카드 + 포인트 + 회전 정답). 내용 생략으로 여백을 만들지 말고 쪽을 늘려서 여유를 만든다.
- **문체는 교과서체**: "고마운 담요", "죄가 없다" 같은 의인화·감성 수사 금지. 비유는 설명 도구로 최소한만. 구어체("~거든요", "오늘 첫 질문") 금지.
- **"칠판에 이 한 줄" 폐지 → "포인트"**: 개념의 마무리 쪽(B면)에만 두는 요약 박스. 매 쪽 강제 아님.
- **출간 표기**: "강의 판본", "강의용" 등의 워터마크성 문구를 지면에 절대 넣지 않는다. 러닝헤드 우측은 "통합과학 2", 폴리오는 "박찬 과학 | 통합과학 2". (시안 배지는 시안 단계에서만.)
