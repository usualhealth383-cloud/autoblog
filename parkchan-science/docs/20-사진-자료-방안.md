# 사진 자료 보강 방안 (2026-10-13 · 현욱님 승인 대기)

> 그림(도식·그래프)은 코드(SVG)로 그린다 — 수치·화살표를 검수할 수 있어서. **사진은 실제 사진만** 쓴다. AI 로 만든 '가짜 사진'은 과학 교재에서 오류(없는 지형·틀린 결정 모양)를 심을 수 있어 쓰지 않는다. AI 그림(나노바나나)은 캐릭터·분위기 그림에만.

## 1. 어디서 가져오나 — 비용 0원
| 출처 | 쓰는 조건 | 우리 쓰임 |
|---|---|---|
| NASA (images.nasa.gov) | 대부분 저작권 없음(공공 영역). NASA 로고·휘장은 쓰지 않는다. 다른 우주국 사진·허블(STScI 외)·APOD 는 예외일 수 있어 하나씩 확인 | 지구·태양·성운·빙하 변화·황사 위성 사진 |
| USGS · NOAA · CDC(PHIL) | 미국 정부 저작물 = 공공 영역(출처 표기 권장) | 화산·지진·판 경계, 산호 백화, 세균·적혈구 현미경 사진 |
| 위키미디어 공용(Commons) | 파일마다 다름. 공공 영역·CC BY 는 출처만, **CC BY-SA 는 출처 + 같은 조건 표시**(상업 교재 가능) | 광물·화석·생물 사진 |

- 책 뒤 '사진 출처' 쪽과 앱의 사진 아래 한 줄(작가 · 출처 · 라이선스)을 같이 넣는다.
- 상업 판매 교재이므로 **CC BY-NC(비영리)·저작권 표시 없는 검색 이미지는 쓰지 않는다.**

## 2. 받는 방법
이 작업 환경에서는 위키미디어가 공용 IP 요청 제한(429)으로 막혀 있다(2026-10-13 확인). 그래서:
1. 내가 후보 파일 이름·주소·라이선스를 표로 만든다(아래 3절을 채움).
2. 현욱님이 PC 에서 그 주소들을 내려받아 구글 드라이브 '박찬과학 사진' 폴더에 넣는다(20~30장, 약 10분).
3. 내가 드라이브에서 받아 크기를 줄이고(앱 용량), 교재·앱에 넣고, 출처 쪽을 만든다.
