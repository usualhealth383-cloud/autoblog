# 통합과학 교재·학습 앱 시장 조사 (2026-09-01)

> 목적: '박찬 과학' 교재·앱 설계의 벤치마크. 디자인 문법·구성 방식·문항 관행을 파악하기 위한 조사이며, 특정 교재의 문장·그림·문항을 복제하지 않는다.

## 시장 배경

- 통합과학1·2 분권 + 2028 수능 공통 응시 확정으로, 2024년 말~2026년 전 출판사가 신간 출간 경쟁 중.
- 수능 통합과학 문항 형식: 5지선다, ㄱ·ㄴ·ㄷ 합답형이 핵심. 탐구 과정(가설 설정·탐구 설계·자료 해석) 문항 포함. 25문항/40분 → 문항당 약 96초.

## 교재별 요약

### 완자 (비상교육) — 개념 자율학습서의 표준
- 소단원 27개(통과1 기준). 소단원당 "개념 본문 2~3p → 개념 확인 1p → 내신 만점 3p → 실력 UP 1p"의 고정 리듬. '완자쌤 비법특강' 코너.
- **본문 첨삭(말풍선식 부연) + 날개단(사이드바)의 짤막한 '날개 개념'**이 브랜드 정체성. '암기해!'·'주의해!'·'궁금해?' 아이콘 팁 박스. 그림·그래프에도 첨삭.
- 3단계 문제(개념 확인→내신 만점→실력 UP), 전국 기출 분석 기반. 해설은 전 문항 + 그림 곁들인 "꼼꼼 문제 분석".
- 인기 요인: "개념만 읽어도 시험 대비", 내신 적중률, 과외하듯 친절한 첨삭. 인강 교재로 채택될 만큼 표준화. 기출 전용 '완자 기출PICK'과 2책 체제.

### 오투 (비상교육) — 시각자료 중심 + 분권 시험대비
- 통과1 총 280쪽 = 진도교재 168p + 해설 56p + **시험대비 별책 56p** (물리적 분권).
- 개념 정리 → 개념 확인 → **자료 분석(탐구/그림 독립 코너)** → 1점→2점→3점 단계 문제. 별책은 기출 분석→기출→예상문제.
- 인포그래픽형 개념 정리(개념 서술은 완자보다 간결). 학교 기출 통계 기반 출제율 높은 문제 선별.

### EBS 개념완성 / 수능특강 계열
- 개념완성: 교과서 개념 → 수준별 유형 → 수능 유형. 대단원명 = 교육과정 영역명 그대로.
- 수능특강 과탐 전통 편집: 개념 + '과학 돋보기'·'탐구자료 살펴보기' 박스 + **2점/3점 테스트** 배점별 분리.
- 2028 대비 신규: 수능 스타트(예시문항 분석), **수능 빌드업(메인북+워크북, 개념 정리→다지기→적용→수능 대비 4단계)**, 50일 통합과학(50테마 속성).

### 마더텅 — "해설이 문제편보다 두꺼운" 기출 전문
- 기본 개념서: 5종 교과서 통합 정리 + 내신 415제 + OX·단답 499제 + 서술형 68제 + 미니모의고사 + 2028 예시문항 부록.
- **해설편이 문제편보다 두꺼움**: 첨삭 해설, 해설편에 문제 재수록(두 권 오가지 않게), 오답 선지별 분석, 전 문항 유튜브 해설 연동.
- '까만책/빨간책' 색상 브랜딩. 빨간책(모의고사)은 **시험지 재현용 갱지+흑백**.

### 자이스토리 (수경) — 기출 + 입체 첨삭 해설
- 개념 정리 + '출제 0순위 특강'(빈출 실험·탐구 특강) + 내신 필수 + 중단원 마무리 + 수능 유형 특강 + 2028 예시문항 전체 수록.
- **입체 첨삭 해설**(정답 단서·오답 함정 시각 표시), 대표 문항 과외식 풀이 코너.

### 셀파 (천재) — 서술형·수행평가 차별화
- 핵심 개념 + '셀파 세미나'(빈출 자료 집중 분석) + 내신 기초/실전 2단계 + **수행평가·서술형 전용 코너**.

### 하이탑 (동아) — 심화 개념서
- 개념 모아 정리→기본→적용→통합 실전→사고력 확장 5단계 + '심화 강의'(물·화·생·지 상위 개념 선행).
- 최상위권용. "내신 유형과 괴리, 일반 학생에겐 과함"이라는 평도 뚜렷 → 우리 타겟(학원 원생 전체)에는 완자형이 기준, 하이탑형은 심화 코너로만.

## 공통 디자인 문법 (업계 관행 → 우리 설계 기준)

**책 아키텍처**
1. 대단원 = 교육과정 영역명 그대로. 소단원 25~30개 분할.
2. 소단원 고정 리듬: 개념 2~4p → 확인 1p → 내신 유형 2~4p → 심화/수능형 1~2p. 개념서 개념:문제 ≈ 4:6~5:5.
3. 분권 관행: 해설지는 분리형 별책이 표준. (오투식 시험대비 별책 / EBS식 메인북+워크북 / 마더텅식 해설편 역전)

**지면 문법**
4. **본문 1단 + 날개단(사이드바)** 구조가 개념서 표준. 날개단: 용어 정의, 보충·심화, 시험 포인트.
5. **첨삭 문화**: 그림·그래프·해설에 손글씨풍 말풍선/화살표 주석 — "옆에서 과외하는 느낌"이 상위권 교재들의 공통 셀링 포인트.
6. 이름 붙인 고정 코너가 브랜드 자산 (완자쌤 비법특강, 셀파 세미나, 출제 0순위 특강, 과학 돋보기 등). **탐구/실험 자료 분석을 독립 박스로** 두는 것이 과학 교재 특유 문법.
7. 색도: 개념서는 풀컬러 인포그래픽 지향(추정 포함), 실전 기출서는 의도적 흑백+갱지(시험지 모사). "학습용 컬러 / 실전용 시험지 재현" 이원화.
8. 난이도 라벨을 지면 상단에 명시 (1점/2점/3점, 기본→실전→사고력 등).

**문항 문법**
9. 유형 사다리: 개념 확인(OX·빈칸·단답) → 내신 유사(5지선다+서술형) → 학평·수능형(ㄱㄴㄷ 합답형, (가)/(나) 자료 제시형).
10. 서술형은 별도 트랙 (내신 필수).
11. 해설 상위 표준 = 전 문항 해설 + 오답 선지별 해설 + 그림 첨삭 + 영상 해설 연동.
12. 2028 수능 예시문항 수록이 신간 공통 부록 관행.

| 앱 | 핵심 기능/UX | 유료화 |
|---|---|---|
| 콴다 | 사진 촬영→유사 풀이 검색, AI 풀이, 커뮤니티 | 무료(광고) + 프리미엄 월 18,500원 |

| 족보닷컴 | 학교별 내신 기출 + 예상문제 | 유료 구독 |

- **"과학 전용 1일 1문제" 단일 컨셉의 뚜렷한 대표 앱은 확인되지 않음** — 데일리 학습은 종합 앱의 부가 기능으로만 존재. 포지셔닝 공백 가능성.
- UX 공통: 카메라 검색이 진입 표준, 오답노트 자동화, AI 취약 유형 진단, 광고 무료 + 월 구독(1.8~2만원) 이중 구조.

## 시사점 (박찬 과학 설계 방향)

1. **교재 포지션**: 완자형(친절한 개념+첨삭) 뼈대 + 오투형 인포그래픽 + 마더텅급 해설 상세도. 심화는 하이탑처럼 본문에 섞지 않고 별도 코너로 격리.
2. **차별화 축**: ① 통합과학 전용 1일 1문제(시장 공백), ② 교재↔앱 연동(교재 단락 = 앱 개념 카드 = 문제 태그가 같은 DB), ③ 학원 오프라인 수업과의 결합.
3. **가격 준거**: 앱 구독 시장가는 월 1.8~2만원대. 원생 무료 정책의 대외 가치가 월 2만원 상당으로 설명 가능.
