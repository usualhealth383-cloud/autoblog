# 외부 검수 안내 — ChatGPT(또는 사람)에게 앱 검수 맡기기

> 만든 날 2026-10-13. 목적: 출시 전에 **다른 눈**으로 박찬 과학 앱을 실제로 써 보게 하고, 받은 지적을 검증해 반영한다.
> 결과는 `docs/18-검수-결과.md` 에 모은다(자체 검수 포함). 외부 지적도 **그대로 믿지 않고** 화면·코드·교과서로 확인한 뒤 고친다.

**알려진 제한(검수자에게도 알려 줄 것)**
- 지금 공개판은 **로컬 모드**다 — 서버 없이 그 브라우저 안에서만 돈다. 여러 기기 동기화·실제 푸시·결제·카메라 QR 출석·문자 발송은 브라우저에서 안 되거나 흉내만 낸다(안드로이드 앱 + 서버 연결 뒤 확인할 몫).
- 예시 기록은 `tools/make_review_fixtures.py` 가 고정 시계로 앱을 실제로 눌러 만든다. 앱을 크게 바꾸면 다시 만든다: `python3 tools/make_review_fixtures.py` → `python3 tools/review_pack.py`(PDF도 새로) → 시험 `tools/e2e_review_entry.py`.
- 검수 입구는 그 브라우저의 기존 앱 기록을 따로 보관했다가 '원래 기록으로 되돌리기'로 돌려놓는다. 실제로 쓰는 폰에서는 열지 않는 편이 안전하다.

## 2. ChatGPT 에 맡기는 법

| 방법 | 언제 | 하는 일 |
|---|---|---|
| **A. 에이전트(브라우저를 직접 조작)** — 권장 | ChatGPT 에서 에이전트 모드를 쓸 수 있을 때 | 에이전트 모드를 켜고 아래 §3 프롬프트를 붙여 넣는다. 검수 입구를 열어 직접 눌러 본다 |
| B. 화면 PDF | 에이전트가 없거나 빠르게 볼 때 | `review-screens.pdf` 를 내려받아 대화에 올리고 §3 프롬프트를 붙여 넣는다(맨 위 '방법 B' 줄을 지우지 않는다) |
| C. 내용 정확성만 깊게 | A·B 뒤 두 번째 회 | §4 프롬프트 — 과학 내용·해설만 본다 |

한 번에 다 시키면 얕아진다. **A(또는 B) 한 번 → 결과를 여기 붙여 넣기 → C 한 번** 순서를 권한다.

## 5. 받은 결과를 다루는 법(이 저장소 쪽)
1. ChatGPT 답을 통째로 현욱님이 세션에 붙여 넣는다.
2. 지적마다 **재현 → 사실 확인**(과학 내용은 교과서·공식 자료, 화면은 같은 순서로 직접 눌러 보기) → `docs/18-검수-결과.md` 표에 '맞음/틀림/판단 필요'로 적는다. 외부 검수도 틀릴 수 있다 — 확인 없이 고치지 않는다.
3. 맞는 것은 고치고 시험을 붙인다. 원장님 판단이 필요한 것은 `docs/16-원장님-할일.md` 로.
