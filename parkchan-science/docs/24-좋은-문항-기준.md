# 24. 좋은 문항 기준 — 사고력을 키우는 문제만 (2026-10-13)

현욱님 「틀린 내용이 있으면 안 돼. 문제를 만들더라도 학생이 사고력과 추론력을 신장시킬 수 있는 좋은 문제여야지. 문제를 위한 문제는 없어야 돼.」
계기: GPT 검수 ③ — 문법만으로 풀리는 빈칸 선지, 조건이 빠진 단정, 다른 단원 문장이 붙은 오답 해설, 교육과정 밖 이온 수 역산.
모든 문항(본책 STEP·보강·실력 다지기·앱 자동 문항·과제)에 적용한다. 새로 쓰거나 고칠 때 이 문서로 검사하고, 통과하지 못하면 내보내지 않는다.

## 1. 내보내지 않는 문항 — '문제를 위한 문제'
| 꼴 | 알아보는 법 | 처리 |
|---|---|---|
| X1 문법·글자 수로 풀림 | 정답만 어미·품사가 앞뒤 문장에 맞음, 정답만 길거나 짧음, 정답에만 발문 낱말이 반복됨 | 선지를 같은 꼴·같은 길이로, 실제 헷갈리는 개념으로 |
| X2 낱말 맞히기뿐 | 본문 문장을 그대로 옮기고 한 낱말만 비움. 생각 없이 기억만 묻음 | 사고력 문제로 세지 않는다. '빈칸 떠올리기'(인출 연습) 칸에만 둔다 |
| X3 정답이 둘 이상이거나 조건이 빠짐 | 조건(공기 저항 무시·정지에서 출발·같은 높이·묽은 수용액…)을 빼면 다른 답도 맞음 | 조건을 발문에 적는다 |
| X4 말장난 함정 | 개념이 아니라 낱말 하나 바꾸기, 이중 부정, '않은 것'의 남발 | 개념의 실제 오해로 함정을 판다 |
| X5 범위 밖 | 성취기준 해설·고려 사항이 빼라고 한 계산·암기(예: 중화 과정 이온 수 역산) | 지우지 않고 `data-adv="1"` '(심화)'. 추천·과제·숙련도에서 뺀다 |
| X6 가짜 맥락 | 숫자·이야기를 덧칠했을 뿐 과학 판단이 없음 | 실제 자료로 바꾸거나 '가상의 자료'로 밝히고 판단을 묻는다 |
| X7 틀린 사실·과한 일반화 | 늘·반드시·모든·~에만·전부 같은 단정(`tools/absolute_audit.py`) | 근거(교과서·공식 자료)로 조건을 붙인다 |
| X8 해설이 문제를 설명 못 함 | 오답 해설이 다른 개념 문장이거나 정답만 되풀이 | 문제 조건 → 그 선지의 잘못 → 바른 판단 순서로 쓴다 |

## 2. 좋은 문항의 꼴 — 소단원마다 섞는다
- **설명**: 처음 보는 현상을 배운 원리로 설명한다(왜 그럴까 → 원리 → 결과).
- **예측**: 조건을 바꾸면 어떻게 될까(변인 하나만 바꾸기).
- **자료 해석**: 표·그래프에서 경향·비율을 읽고, 근거가 되는 칸을 고른다. '이 자료만으로 알 수 없는 것'도 판단하게 한다.
- **탐구 설계·평가**: 통제 변인, 대조군, 측정의 한계를 판단한다.
- **오개념 진단**: 선지마다 실제로 학생들이 하는 잘못을 하나씩 담는다(바로알기와 1:1).
- **의사 결정**: 근거로 두 선택을 견준다(기후·에너지·감염병·인공지능 단원).
- 소단원 문항 배분(STEP·보강·실력 합계): 떠올리기·이해 40 % 안쪽, 나머지는 적용·자료·탐구·추론. 실력 다지기는 자료·추론이 절반 넘게.

## 3. 쓸 때 점검표(문항마다)
1. 이 문제를 풀려면 무엇을 **생각**해야 하나? 한 줄로 쓸 수 없으면 다시 쓴다.
2. 정답이 하나뿐인가? 조건은 발문에 다 있는가?
3. 오답 선지 하나하나가 어떤 오개념인가? 이름 붙일 수 없는 선지는 바꾼다.
4. 문법·길이·낱말 반복으로 답이 보이지 않는가?
5. 성취기준 안인가? 넘으면 '(심화)'로 밝혔는가?
6. 사실·수치는 교과서·공식 자료와 맞는가? 출처는 `docs/21`·소단원 출처 칸에 있는가?
7. 해설은 '왜 이 답인지'와 '왜 그 오답이 틀렸는지'를 이 문제 조건으로 설명하는가?

## 4. 검사 도구
- `tools/absolute_audit.py`: 단정 표현 목록.
- `tools/check_content.py`: 보기 누락, 숫자 뭉개짐, 자동 문항 오답 해설 출처.
- 문항 품질 전수 분류표: `review/문항-품질-분류.md`. 문항마다 유형과 X1~X8 결함을 매기고, 결함 문항의 처리 상태를 적는다.
- 사람 감수: 교사 감수표(`review/교사-감수표-보강.*`)에 '사고력 문항인가' 칸을 둔다. 이 판정은 AI 검수만으로 끝내지 않는다.
