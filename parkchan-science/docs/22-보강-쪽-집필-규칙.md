# 22. '시험에 나오는 보강' 쪽 집필 규칙 (2026-10-13)

> 목적: `docs/21` 의 빠진 주제를 **우리 말·우리 그림·우리 문제**로 채워 본책·앱에 함께 싣는다. 정식 출간 교재다 — 완자 등 남의 책 문장·문제·그림을 옮기거나 바꿔 쓰지 않는다(저작권). 개념·사실은 교육과정(별책 9)·교과서 공통 내용·공식 자료(KRISS·기상청·NASA·USGS 등)로 확인해 쓴다. 수치는 출처를 주석으로 남긴다.

## 1. 어디에 넣나
- 그 소단원 본책 `chapter.html` 에서 **마지막 개념(또는 탐구) 쪽 다음, 첫 STEP 문제 쪽 앞**에 `<div class="page plus">` 를 넣는다 — 보통 개념 1~2쪽 + 문제·해설 1~2쪽(시범 1303 은 4쪽). 넘치면 글꼴을 줄이지 말고 쪽을 나눈다. 쪽 번호(folio)는 `?` 로 두고, 모든 소단원이 끝난 뒤 `python3 tools/renumber_book.py book|book2` 를 한 번 돌린다(손으로 매기지 않는다).
- 기존 쪽·문항·바로바로 체크는 **고치지 않는다**(학생 복습 기록의 문항 id 가 바뀐다). 보강 쪽에 `.quickcheck`·`.q`·`.step-head`·`.lab`·`.anstable` 을 쓰지 않는다.

## 2. 꼴(추출기 `parse_plus` 가 읽는다)
```html
<!-- ═════════════ 보강 · 시험에 나오는 보강 ═════════════ -->
<div class="page plus">
  <div class="runhead">(그 장의 runhead 를 그대로)</div>
  <div class="plus-h"><span class="tag">시험에 나오는 보강</span><span class="tt">이동 거리·변위 · 속력·속도 · 가속도</span></div>
  <section class="plus-sec" data-concept="1">            <!-- 이 내용이 이어지는 개념 번호(본책 개념 번호) -->
    <h3 class="psec">이동 거리와 변위</h3>
    <p class="body">…우리 말로 쓴 설명…</p>
    <figure><svg …>…</svg><figcaption>그림 보강 1 | …</figcaption></figure>
    <div class="pkey">한 줄 정리: …</div>
  </section>
  …
  <div class="pq-h">보강 문제</div>
  <div class="pq" data-n="1" data-concept="1" data-type="mc" data-answer="③">
    <div class="stem"><span class="pqno">1</span>…발문… <span class="difficulty">●●○</span></div>
    <!-- 자료가 있으면 <div class="exp">…</div> 또는 <figure><svg>…</svg></figure> -->
    <!-- 합답형이면 <div class="bogi-box"><div class="bt">보기</div>ㄱ. …<br>ㄴ. …<br>ㄷ. …</div> -->
    <ul class="choices"><li>① …</li><li>② …</li><li>③ …</li><li>④ …</li><li>⑤ …</li></ul>
  </div>
  …
  <div class="psols"><div class="pq-h">보강 문제 해설</div>
    <div class="psol" data-n="1"><p><b>③</b> …왜 맞는지…</p><div class="wrongbox"><div class="wt">바로알기</div><p><b>①</b> …</p></div></div>
  </div>
  <div class="folio"><span>(장 이름)</span><span class="num">?</span></div>
</div>
```
- `data-type`: `mc`(5지 선다) · `multi`(합답형 ㄱㄴㄷ) · `ox`(data-answer O/X) · `blank`(빈칸 ＿＿＿, data-answer 낱말) · `essay`(서술형, data-answer 비움 — 해설에 채점 기준).
- 소단원마다 **보강 개념 2~4칸 + 보강 문제 6~10개**(ox·blank 2~3, mc 2~3, multi 2~3, 자료·계산형 1개 이상, essay 0~1). 난이도 ●○○ ~ ●●●.
- CSS: 그 장의 `<style>` 끝에 아래를 한 번 붙인다(이미 있으면 그대로).

## 3. 글 규칙
- 본책 문체(‘~다’ 체)와 용어(편수자료: 라이보솜·마이토콘드리아 등, 대한화학회 원소 이름)를 그대로. 숫자와 단위 사이 띄어 쓰기(‘9.8 m/s²’, ‘70 km’), 위·아래 첨자는 `<sup>`·`<sub>`.
- 교육과정이 '다루지 않는다'고 한 것(산화수·엔탈피·브뢴스테드 등, `docs/19` 1절)은 쓰지 않는다. 범위 밖이지만 시험에 나오는 것은 제목에 ‘(심화)’.
- 문제는 고1 학평·수능 꼴. 정답은 **하나**, 해설은 정답을 설명하고 바로알기는 오답마다 한 줄. 계산은 해설에 식과 숫자를 다 쓴다.
- 그림은 SVG 로 직접(글자 viewBox 기준 인쇄 8 pt 이상 · 첨자 6 pt, 그림 안 글자는 `font-family="PC Sans"`). 화살표 방향·값·눈금이 본문·문항과 맞게.

## 4. 끝내는 조건(소단원마다)
1. `bash tools/check_chapter.sh <id>` → QA PASS · TEXT PASS · 넘침 없음
2. `python3 tools/book_fig_audit.py <chapter.html>` → BOOK FIG OK
3. `python3 tools/fig_one.py <chapter.html> '<그림 속 글자>' <png>` 로 그림을 직접 본다
4. `python3 tools/plus_check.py <chapter.html>` → PLUS OK(자리·정답 꼴·해설 짝·보기·번호·글 규칙)
5. 보강 문제를 **직접 다시 풀어** 정답이 하나인지 확인
6. (모두 끝난 뒤 한 번) `extract_bank.py` → 문항 id 집합이 늘기만 했는지(기존 id 그대로) · `fig_all_audit.py` · 앱 빌드 · e2e
