# 박찬 과학 통합과학2 — 강의용 교재 제작 브리프 (소단원 1개 = 파일 1개)

원장님이 수업 중 그대로 읽으며 가르치는 **출간용 강의 교재**다. 본책(`book2/chapter-XXXX/chapter.html`)의 개념 5개를
**개념 1개 = 2쪽 펼침**으로 옮긴다. 완성 예시(합격본): `book2/lecture-edition/L-2203.html` — **이 파일의 구조·클래스·분량을 그대로 따른다.**

## 산출물
- `book2/lecture-edition/L-XXXX.html` (XXXX = 본책 챕터 번호). `<head>`는 L-2203과 동일(`<link rel="stylesheet" href="lecture.css">`),
  `<body data-unit="I|II|III" style="--pg-start:0;">`. 단원: 21xx→I, 22xx→II, 23xx→III (팔레트는 CSS 변수로 자동).
- 검증: `bash book2/lecture-edition/render_one.sh L-XXXX` 가 **TEXT PASS + OVERFLOW PASS**여야 하고,
  `_previews/L-XXXX/pN.png` 를 **전 쪽 직접 열어** 라벨 충돌·잘림·빈 페이지·폴리오 겹침이 없는지 확인한다.

## 페이지 구조 (개념마다 A면·B면)
**A면**: `a-lesson`(개념 0N) → `a-title`(교과서체 제목 — 부제는 `<span class="soft">`) → `a-flow` 뼈대 3걸음(①②③, 한 칸에 빈칸 ㉠ 1개) →
`a-fig` 큰 그림 1장(+figcaption "그림 N | …") → (자료형 그래프·단면도·표라면) `howto` "그림 읽는 법" 3~4단계 → `a-script` 본문 1~2문단.
**그림이 있는 면에는 반드시 그 그림을 읽는 본문이 함께 있어야 한다.**
**B면**: `a-script` 심화 문단 1~2개(빈칸 ㉡㉢ 포함) → `terms` 용어 정리표 3항 → `myth` 오해✗/진실✓ 카드 2개 → `point` 포인트 → `ans-line` 회전 정답.
자료형이면 A면 그림 아래에 `facts` 숫자 칩 3개를 둘 수 있다.

## 문체 규칙 (엄격)
- **교과서체**. 본책의 강의체("~거든요", "오늘 첫 질문", "죄가 없다", "고마운 담요", 의인화·감탄·수사)는 전부 교과서 서술로 바꾼다.
  비유는 설명 도구로 한 번만, 제목·라벨에 쓰지 않는다. 박찬쌤 말풍선·펜글씨는 넣지 않는다.
- **사실은 본책 것만**. 새 수치·사례를 지어내지 않는다. 본책 수치가 "확인 필요"면 그대로 표기.
- 지면에 "강의 판본", "강의용", "시안" 같은 표기 금지. 러닝헤드 우측 "통합과학 2", 폴리오 "박찬 과학 | 통합과학 2".
- 여백 규칙: 행간·여백을 줄여 지면을 벌지 않는다. 넘치면 ① 라벨·출처류를 그림 속으로 ② 문단 통합 ③ 그림 축소. 그래도 넘치면 문단을 다음 면으로.

## 본책 요소의 변환표
| 본책 | 강의용 |

| 본문 2문단 | A면 1~2문단 + B면 1~2문단(교과서체로 다시 씀, 빈칸 ㉠㉡㉢ 배치) |
| 그림(SVG) | **본책 그림을 확대만 해서 재사용 금지.** 본책에서 가져오는 것은 '정보'이지 '모양'이 아니다. 아래 '장면형 재작화 기준'으로 새로 그린다. 캡션은 교과서체 |
| 날개 노트 term | 용어 정리표 3항 |

## 그림 규칙 — 장면형 재작화 기준 (원장 지시, 위반 시 불합격)
1. **실제 대상을 그린다.** 카드 안에 작은 아이콘·글상자를 나열하는 방식 금지. 바다면 바다 단면, 땅이면 땅의 변화, 실험이면 실험 장치.
2. **원인 → 결과가 그림 안에서 보인다.** 글로 설명해야 이해되는 그림은 실패다.
3. **라벨 8pt 이상**, 작은 글씨 금지. 그림이 지면 폭(600px)을 채우고 여백보다 커야 한다.
4. **배경을 실제 장면처럼**(하늘·바다·땅·실험대). 화살표: 빛·에너지 = 테이퍼드 광선, 복사·열 = 물결, 흐름 = 굵고 명확하게. 클립아트식 직선+삼각 마커 금지.
5. 데이터 그래프는 실데이터 비례 + 출처를 그림 안에 표기. 아이콘은 뜻이 한눈에.
6. 합격 기준: **"공부 못 하는 학생이 그림만 보고도 무슨 일이 일어나는지 아는가."** 미리보기를 열어 이 질문에 '예'가 아니면 다시 그린다.
7. 장면형 예시: L-2203 그림 1(온실효과 단면), 그림 4(엘니뇨 바다 단면), 그림 5(사막화 4장면 흐름).

## 그림 규칙 (기술)
- 본책 SVG는 마커 id(`arrP` 등)를 참조하므로, 파일 상단 `<svg class="defs-only">` defs에 **참조되는 모든 마커 id**를 정의한다(L-2203 참고). 미정의 마커 = 화살촉 실종.
- 화살표: 직선+삼각 마커(클립아트 느낌) 대신 빛·에너지는 테이퍼드 광선, 복사는 물결 화살표(L-2203 개념 01 그림 참고). 흐름도·축·순환 화살표는 가는 표준 화살표 유지.
- 아이콘은 뜻이 한눈에 읽히게(추상 기호 금지). 그래프는 실데이터 비례(높이·낙폭이 실제 값 비례), 있으면 출처를 그림 안에 작게.
- 그림 읽는 법: 고유명사·단위·그래프 무늬를 처음 보는 학생 눈높이로. "공부 못 하는 아이도 이 박스만 읽으면 그래프가 읽히는가"가 기준.

## 빈칸·정답
- 개념마다 ㉠(뼈대) ㉡㉢(본문) 3개. 정답은 B면 맨 아래 `ans-line`(180° 회전)에 "정답 ㉠ … ㉡ … ㉢ … — 한 줄 오답 주의".
- 빈칸 정답은 본책에 명시된 핵심 용어·수치만.
