# 원장 운영 안내 — 앱을 실제로 굴리는 법

개발을 모르셔도 됩니다. 앱 안에서 다 됩니다.
**내 정보 › 원장님이신가요 › 비밀번호** 를 넣으면 원장 화면이 열립니다.

---

## 하루 · 한 주 · 한 달에 할 일

| 언제 | 무엇 | 어디 |
|---|---|---|
| 수업 시작 전 | 출석 코드 띄우기 (30초마다 바뀜) | 원장 › 출석 |
| 수업 뒤 | 폰 없는 학생 직접 체크 | 원장 › 출석 › 이름 옆 체크 |
| **매일 1회** | 신고된 글·댓글 확인 | 원장 › 이야기 |
| 필요할 때 | 휴강·시간 변경·준비물 알리기 | 원장 › 공지 |
| 시험 2~3주 전 | 시험·보강 일정 반 별로 보내기 | 원장 › 일정 |
| 신입생 등록 시 | 코드 발급 후 문자로 전달 | 원장 › 학생 |
| 매달 | 반별 출석률·진도 확인 | 원장 › 통계 |

**이야기 확인은 하루 한 번을 약속해 두었습니다**(이용약관 제8조의2 ④).
지키지 못하면 약관을 고쳐야 하니, 확인 주기는 실제로 지킬 수 있는 만큼으로 정하십시오.

---

## 1. 수강생 등록과 코드

원장 › 학생 › 이름·반·연락처·만료일 → **코드 만들기** → 6자리 코드가 나옵니다.

- 학생은 **내 정보 › 학원 코드 등록**, 보호자는 **자녀 연결**에 같은 코드를 넣습니다.
- 1인 1코드입니다. 만료일이 지나면 저절로 닫혀 전 범위가 잠깁니다.
- 코드가 나오면 **문자 보내기** 단추로 바로 보낼 수 있습니다.
- 학생 이름을 누르면 그 학생의 출석·진도가 보입니다.

## 2. 출석

원장 › 출석에 **4자리 숫자**가 크게 뜹니다. 30초마다 바뀝니다.
학생은 홈의 **출석 체크**에 그 숫자를 칩니다. 지각 여부는 반 시작 시각을 기준으로 자동 판정됩니다.

- 폰을 안 가져온 학생은 이름 옆을 눌러 직접 체크합니다.
- 코드를 옆 반에 넘겨 대리 출석하는 것은 약관 위반입니다(제8조 ③).

## 3. 공지

자주 쓰는 문구(휴강 · 시간 변경 · 교실 변경 · 준비물 · 시험)를 누르고 반을 고르면 발송됩니다.
읽음 수가 표시되고, **안 읽은 학생에게만 문자**를 보낼 수 있습니다.

## 4. 일정 (시험·보강·휴강)

원장 › 일정에서 반·날짜·제목·종류를 넣어 보내면, 학생과 보호자의 **일정** 화면에 자동으로 들어갑니다.
학원이 보낸 일정에는 '학원' 표시가 붙고 학생이 지울 수 없습니다.

시험 일정을 보낼 때 학생에게 **범위를 직접 걸어 두라고 안내**해 주세요.
학생이 자기 일정에 범위를 걸면 그 일정에서 바로 해당 범위 문제로 넘어갑니다.

## 5. 이야기(커뮤니티) 운영 — 가장 신경 쓸 곳

원장 › 이야기에 **신고된 글과 댓글**이 모입니다. 신고가 3건 쌓이면 학생 화면에서는 이미 가려져 있고
원장님만 원문을 봅니다.

지워야 하는 글
1. 실명·전화번호·주소·SNS 아이디가 적힌 글 — 본인 것이라도 지웁니다
2. 시중 문제집·기출문제 **원문을 그대로 올린 글** (저작권)
3. 비방·욕설·따돌림
4. 광고, 과외·과제 대행 제안
5. 시험 문제를 미리 흘린 글

**자·타해가 걱정되는 글**을 보면 글을 가리고 학생에게 연락한 뒤,
청소년 상담 **1388**, 자살예방 상담 **109** 를 안내해 주세요.

신고가 없어도 가끔 이야기 탭을 직접 둘러봐 주세요. 신고는 늦게 옵니다.

## 문제가 생겼을 때

| 증상 | 원인과 해결 |
|---|---|
| 학생이 "코드가 안 맞대요" | 만료일이 지났는지 확인. 지났으면 새 코드를 발급 |
| 출석이 안 찍힌다 | 화면의 숫자는 30초마다 바뀝니다. 다시 띄우고 새 숫자를 부르세요 |
| 진도가 사라졌다 | 서버 연동 전이면 진도는 그 기기에만 있습니다. 로그인하면 계정으로 따라옵니다 |
| 공지를 못 봤다 한다 | 읽음 수를 확인하고 안 읽은 학생에게만 문자 |
| 앱이 안 열린다 | 인터넷 연결을 확인. 받아 둔 개념과 문제는 연결 없이도 열립니다 |

## 개인정보 요청이 오면

- 학생·보호자가 **열람·정정·삭제·처리 정지**를 요구하면 응해야 합니다(개인정보 보호법 제35~37조).
- 계정 삭제는 학생이 **내 정보 › 계정 삭제**로 직접 할 수 있습니다.
- 앱을 지운 뒤 요청이 오면 본인 확인 후 **10일 이내** 처리하고 회신합니다.
- 만 14세 미만 아동의 법정대리인은 자녀의 게시물 삭제와 커뮤니티 이용 중지를 요청할 수 있습니다.

## 아직 원장님 손이 필요한 값

`CFG.academy`(학원 이름) · `CFG.phone` · `CFG.kakao` · `CFG.email` · 반 편성과 시작 시각 ·
Supabase 계정 · 서명 키 · Play 개발자 계정. 자세한 순서는 `docs/08-출시-체크리스트.md` 에 있습니다.
