# 원장 운영 안내 — 앱을 실제로 굴리는 법

개발을 모르셔도 됩니다. 앱 안에서 다 됩니다.
**내 정보 › 원장님이신가요 › 비밀번호** 를 넣으면 원장 화면이 열립니다.

## 1. 수강생 등록과 코드

원장 › 학생 › 이름·반·연락처·만료일 → **코드 만들기** → 6자리 코드가 나옵니다.

**개원 때처럼 한꺼번에**: 원장 › 학생 › *여러 명 한꺼번에 등록* 에 엑셀의 **이름·반·연락처** 세 칸을 복사해 붙여 넣고 → *미리 보기* (없는 반·이미 있는 학생·제목 줄은 알아서 걸러 표시) → *코드 만들기* → **코드 목록 내려받기(엑셀)** 로 보관하고, 줄마다 *문자* 로 보냅니다.

- 학생은 **내 정보 › 학원 코드 등록**, 보호자는 **자녀 연결**에 같은 코드를 넣습니다.
- 형제·자매가 함께 다니면 보호자는 한 계정에서 **자녀 한 명 더 연결**로 둘 다 봅니다(자녀 화면 맨 위 이름을 눌러 바꿈). 반 일정도 자녀별로 들어갑니다.
- 1인 1코드입니다. 만료일이 지나면 저절로 닫혀 전 범위가 잠깁니다.
- 코드가 나오면 **문자 보내기** 단추로 바로 보낼 수 있습니다.
- 학생 이름을 누르면 그 학생의 출석·진도, 학생 앱·보호자 연결 여부가 보입니다.
- 같은 창의 **학생 정보 고치기**에서 이름·반·연락처·만료일을 바꿉니다. **+1개월 · +3개월 · +6개월** 단추로 연장이 한 번에 됩니다.
- 학기가 바뀌면 학생 탭 맨 위 **수강 기간 한꺼번에 연장**: 반과 새 만료일을 고르면, 그보다 먼저 끝나는 학생만 늘어납니다(이미 더 긴 학생은 그대로).
- **한 코드는 학생 계정 하나에만** 연결됩니다(친구에게 코드를 넘겨 쓰는 것을 막기 위해). 학생이 계정을 새로 만들어 "이미 다른 학생 계정에 연결" 이라고 나오면,
  그 학생 창의 **학생 계정 연결 풀기**를 누른 뒤 새 계정에서 다시 등록하게 하세요.

## 1-2. 만 14세 미만 학생 — 보호자 동의 확인 (법으로 꼭 해야 하는 일)

만 14세 미만이 가입하면 앱은 교재·문제는 그대로 쓰게 하고, **이야기와 진도 저장만** 보호자 동의 뒤에 엽니다.
동의는 둘 중 하나로 확인합니다(개인정보 보호법 제22조의2).

1. **동의 페이지(보통 이렇게)**: 학생이 앱에서 *보호자에게 동의 요청 보내기* → 보호자 폰에 문자로 링크가 가고 → 보호자가 페이지에서 동의.
   그다음 **원장 › 학생 › '보호자 동의 확인'** 에 *웹 동의* 로 뜨면 **확인 문자 보내기**를 눌러 보호자에게 확인 문자를 보내 주세요. 이 문자까지가 법이 정한 확인 절차입니다.
2. **서면**: 보호자가 학원에 오시면 동의서에 서명을 받고 *서면 동의 받음* 을 누릅니다. 받은 서면은 보관해 두세요.

7일 안에 동의가 없으면 그 아이의 계정은 자동으로 지워집니다(목록에 남은 날수가 보입니다).

## 2. 출석

원장 › 출석에 **4자리 숫자**가 크게 뜹니다. 30초마다 바뀝니다.
학생은 홈의 **출석 체크**에 그 숫자를 칩니다. 지각 여부는 반 시작 시각을 기준으로 자동 판정됩니다.

- 폰을 안 가져온 학생은 이름 옆을 눌러 직접 체크합니다.
- 잘못 찍힌 출석은 원장 › 학생 › 이름 › 출석 기록 옆 **취소**로 지웁니다(최근 7일).
- 틀린 숫자를 여러 번(6번) 넣은 학생은 1시간 동안 막힙니다. 이때는 직접 체크해 주세요.
- 서버와 알림이 연결되면 **보호자 폰에 "○○ 학생 18:02 출석" 알림**이 갑니다.
- 코드를 옆 반에 넘겨 대리 출석하는 것은 약관 위반입니다(제8조 ③).

## 3. 공지

자주 쓰는 문구(휴강 · 시간 변경 · 교실 변경 · 준비물 · 시험)를 누르고 반을 고르면 발송됩니다.
읽음 수가 표시되고, **안 읽은 학생에게만 문자**를 보낼 수 있습니다.
알림이 연결되면 그 반 학생·보호자 폰에 바로 푸시 알림이 갑니다. 잘못 보낸 공지는 **지우기**로 거둡니다.

## 4. 일정 (시험·보강·휴강)

원장 › 일정에서 반·날짜·제목·종류를 넣어 보내면, 학생과 보호자의 **일정** 화면에 자동으로 들어갑니다.
학원이 보낸 일정에는 '학원' 표시가 붙고 학생이 지울 수 없습니다.

시험 일정을 보낼 때 학생에게 **범위를 직접 걸어 두라고 안내**해 주세요.
학생이 자기 일정에 범위를 걸면 그 일정에서 바로 해당 범위 문제로 넘어갑니다.

## 5. 이야기(커뮤니티) 운영 — 가장 신경 쓸 곳

원장 › 이야기에 **신고된 글과 댓글**이 모입니다. 신고가 3건 쌓이면 학생 화면에서는 이미 가려져 있고
원장님만 원문을 봅니다.

지워야 하는 글
1. 실명·전화번호·주소·SNS 아이디가 적힌 글 — 본인 것이라도 지웁니다
2. 시중 문제집·기출문제 **원문을 그대로 올린 글** (저작권)
3. 비방·욕설·따돌림
4. 광고, 과외·과제 대행 제안
5. 시험 문제를 미리 흘린 글

**자·타해가 걱정되는 글**을 보면 글을 가리고 학생에게 연락한 뒤,
청소년 상담 **1388**, 자살예방 상담 **109** 를 안내해 주세요.

신고가 없어도 가끔 이야기 탭을 직접 둘러봐 주세요. 신고는 늦게 옵니다.

## 문제가 생겼을 때

| 증상 | 원인과 해결 |
|---|---|
| 학생이 "코드가 안 맞대요" | 만료일이 지났으면 학생 창에서 만료일만 늘리면 됩니다(새 코드 필요 없음) |
| "이미 다른 학생 계정에 연결" | 학생이 계정을 새로 만든 경우 — 학생 창 › **학생 계정 연결 풀기** |
| "결제했는데 안 열려요" | 이용권 화면의 **구매 복원**을 누르게 하세요. 같은 결제가 두 번 반영되지는 않습니다. 그래도 안 되면 Play 주문번호를 받아 제작자에게 |
| 비밀번호를 잊었다 | 로그인 화면 **비밀번호를 잊었어요** → 메일의 링크 → 새 비밀번호 |
| 비밀번호를 바꾸고 싶다 | 내 정보 › 계정 › **비밀번호 바꾸기** |
| 이야기에서 선생님인 척하는 학생 | 학생은 선생님·원장·관리자 같은 닉네임을 못 씁니다. 원장님 글·댓글에만 **선생님** 표시가 붙습니다 |
| 출석이 안 찍힌다 | 화면의 숫자는 30초마다 바뀝니다. 다시 띄우고 새 숫자를 부르세요 |
| 진도가 사라졌다 | 서버 연동 전이면 진도는 그 기기에만 있습니다. 로그인하면 계정으로 따라옵니다 |
| 공지를 못 봤다 한다 | 읽음 수를 확인하고 안 읽은 학생에게만 문자 |
| 앱이 안 열린다 | 인터넷 연결을 확인. 받아 둔 개념과 문제는 연결 없이도 열립니다 |

## 개인정보 요청이 오면

- 학생·보호자가 **열람·정정·삭제·처리 정지**를 요구하면 응해야 합니다(개인정보 보호법 제35~37조).
- 계정 삭제는 학생이 **내 정보 › 계정 삭제**로 직접 할 수 있습니다.
- 앱을 지운 뒤 요청이 오면 본인 확인 후 **10일 이내** 처리하고 회신합니다.
- 만 14세 미만 아동의 법정대리인은 자녀의 게시물 삭제와 커뮤니티 이용 중지를 요청할 수 있습니다.
