# 박찬 과학 학습 서비스 — 설계 노트 (2026-09-03 착수)

원장님 방향: **한국 모든 고등 수험생이 쓰는 서비스.** 매일 1개념·1문제를 배달하고,
학원 수강생은 코드 인증으로 무료, 그 외 학생은 유료. 교재(통합과학 1·2)가 콘텐츠의 뿌리다.

**근거.** 매일 오는 습관은 무료로 만들어야 사용자가 쌓이고, 결제는 시험 2주 전
몰아볼 때 터진다. 그 순간 "지난 개념이 막혀 있다"가 가장 강한 전환 지점이다.
하루 한 개만 주고 막으면 그 순간이 오기 전에 이탈한다.

**차별점.** 콴다·밀크T는 풀이 도구, EBS는 강의 아카이브다. 우리는 *원장님 강의 그대로의
교재*가 하루치로 배달되고 *학원 수강생은 코드 하나로 전체가 열린다* — 오프라인 학원과
앱이 한 몸인 곳이 아직 없다.

## 3. 레퍼런스 수집 방법 (중요)

Mobbin·Refero·Landbook·Godly는 **작업 환경의 네트워크 정책에서 차단**되어 Claude가 직접 열 수 없다.
따라서 수집은 원장님이, 해체·이식은 Claude가 맡는다.

- Mobbin 무료 한도가 최신 4개 앱이므로, **위 표의 1~4번 화면에 하나씩** 배정해 캡처한다.
- 캡처를 줄 때 한 줄만 덧붙이면 정확도가 크게 오른다 — "이 앱의 *무엇*이 좋았는지"
  (여백 / 색 / 글자 크기 / 카드 모양 / 흐름 중 무엇).
- Claude는 받은 캡처에서 레이아웃 그리드, 여백 리듬, 타이포 계층, 색 역할, 카드 형태를
  뽑아 우리 언어로 옮긴다. 이미지를 베끼지 않고 **구조만** 가져온다(저작권).

## 5. 교재에서 이어받을 디자인 언어

이미 완성된 교재가 서비스의 정체성이다. 새로 만들지 말고 확장한다.

- 단원 색: I 테라코타 `#C1521E` · II 딥틸 `#147D6F` · III 인디고 `#4053B8`
- 타이포: Noto Sans KR 본문, 숫자는 tabular-nums
- 구조 언어: 뼈대 3걸음 → 큰 그림 → 그림 읽는 법 → 본문 → 용어 → 오해✗진실✓ → 포인트
- 화면당 히어로 1개, 나열식 금지 — 교재의 "개념 하나에 두 쪽" 원칙을 화면에 옮긴다

## 6. 학원 운영 — 원장님 손이 가장 적게 가도록

**원장님이 실제로 하시는 일은 이것뿐이다.**

| 시점 | 하실 일 | 나머지는 |
|---|---|---|
| 학기 시작 | 명단 파일 1회 업로드(이름·연락처·수강 기간) | 코드 발급 · 문자 발송 · 만료일이 전부 자동 |
| 중도 등록생 | 알림에서 **[승인]** 한 번 | — |
| 이상 접속 | 알림에서 **[해제]** 한 번 (무시해도 됨) | 자동 잠금은 이미 걸린 상태 |
| 퇴원생 | **아무것도 안 함** | 만료일에 저절로 닫힘 |
| 출석부 | **아무것도 안 함** | QR 스캔으로 시각까지 자동 기록 |

학생도 코드를 손으로 칠 일이 없다 — 문자로 온 링크를 누르면 등록이 끝나므로
"코드가 안 돼요" 문의 자체가 생기지 않는다.

### 코드 오남용을 막는 네 겹
1. **1인 1코드** — 공통 코드는 커뮤니티에 한 번 올라가면 끝. 개인 발급이라 유출 추적이 된다.
2. **기기 1대 고정** — 변경은 월 1회. 돌려쓰기를 막는다.
3. **만료일** — 수강 기간과 연동. 퇴원생이 자동으로 닫힌다.
4. **이상 접속 자동 잠금** — 짧은 시간에 여러 지역에서 접속하면 잠그고 원장님께 알린다.

여기에 **설정 화면에 학생 이름을 크게 띄우는 것**이 공짜로 얻는 억제력이다.
내 이름이 붙은 코드를 친구에게 넘기기는 눈에 띄게 껄끄럽다.

## 7. 출석 — 학원에 붙는 이유

- 학원 입구 화면에 띄운 **QR을 학생이 찍으면 시각까지 기록**된다.
- QR은 **30초마다 바뀌어** 사진 전송으로 대리 출석이 되지 않고, **학원 반경 밖에서는 거부**된다.
- 지각·결석은 자동으로 집계되어 원장 화면의 "처리할 것"에 뜬다.
- **출석과 학습이 한곳에 쌓인다** — "매주 오는데 앱 학습은 3주째 없는 학생"이 보인다.
  출석 앱에도, 학습 앱에도 없는 자리다. 이게 이 서비스의 가장 단단한 차별점이다.

**한계도 적어 둔다.** GPS만으로는 위치 위조 앱에 뚫리므로 QR과 반드시 병행한다.
학생 폰이 없거나 배터리가 없는 경우를 위해 원장님이 명단에서 직접 체크하는 백업 경로가 필요하다.

## 8. 학생이 불편하지 않도록 (원장 지시)

| 흔한 불편 | 우리의 처리 |
|---|---|
| 첫 화면부터 가입을 요구한다 | **가입은 나중에.** 며칠 써 본 뒤 "기록을 지키려면" 시점에만 묻는다 |
| 연속 일수가 끊기면 의욕이 꺾인다 | **연속 일수를 세지 않는다.** 이번 주 진도만 조용히 보여 준다 |
| 알림이 잔소리처럼 온다 | 시각은 학생이 고르고, 안 해도 **재촉하지 않는다** |
| 틀리면 기분이 상한다 | 야단치지 않고 **어디서 갈렸는지만** 짚는다. 맞혔을 때는 짧게 넘어간다 |
| 틀린 문제를 그냥 지나친다 | 오답 노트에 담고 **3일 뒤 한 번 더** 낸다(간격을 둔 재시도가 오래 남는다) |
| 글씨가 작다 | 설정에서 **글자 크기**를 키운다 |
| 지하 강의실·지하철에서 안 열린다 | 오늘 것은 **미리 받아 둔다** |

**톤 원칙.** 오답 화면의 배지는 "오답"이 아니라 **"다시 볼 문제"**다.
낙인을 찍지 않고, 과장된 위로도 하지 않는다 — 담백하게 사실만 짚고 다음 길을 준다.
