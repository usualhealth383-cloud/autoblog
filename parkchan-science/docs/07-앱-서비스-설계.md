# 박찬 과학 학습 서비스 — 설계 노트 (2026-09-03 착수)

원장님 방향: **한국 모든 고등 수험생이 쓰는 서비스.** 매일 1개념·1문제를 배달하고,
학원 수강생은 코드 인증으로 무료, 그 외 학생은 유료. 교재(통합과학 1·2)가 콘텐츠의 뿌리다.

## 1. 무료 / 유료 경계 — "양"이 아니라 "시점"에 긋는다

| 기능 | 무료 | 유료 | 학원 수강생 |
|---|---|---|---|
| 1일 1개념 · 1일 1문제 | ✅ | ✅ | ✅ |
| 지난 회차 다시 보기 | 최근 7일 | 전체 | 전체 |
| 교재 전 범위 열람 | ✗ | ✅ | ✅ |
| 오답 노트 · 약점 리포트 | ✗ | ✅ | ✅ |
| 시험 전 단원 몰아보기 | ✗ | ✅ | ✅ |
| 인증 방식 | — | 결제 | 학원 코드 |

**근거.** 매일 오는 습관은 무료로 만들어야 사용자가 쌓이고, 결제는 시험 2주 전
몰아볼 때 터진다. 그 순간 "지난 개념이 막혀 있다"가 가장 강한 전환 지점이다.
하루 한 개만 주고 막으면 그 순간이 오기 전에 이탈한다.

**차별점.** 콴다·밀크T는 풀이 도구, EBS는 강의 아카이브다. 우리는 *원장님 강의 그대로의
교재*가 하루치로 배달되고 *학원 수강생은 코드 하나로 전체가 열린다* — 오프라인 학원과
앱이 한 몸인 곳이 아직 없다.

## 3. 레퍼런스 수집 방법 (중요)

Mobbin·Refero·Landbook·Godly는 **작업 환경의 네트워크 정책에서 차단**되어 Claude가 직접 열 수 없다.
따라서 수집은 원장님이, 해체·이식은 Claude가 맡는다.

- Mobbin 무료 한도가 최신 4개 앱이므로, **위 표의 1~4번 화면에 하나씩** 배정해 캡처한다.
- 캡처를 줄 때 한 줄만 덧붙이면 정확도가 크게 오른다 — "이 앱의 *무엇*이 좋았는지"
  (여백 / 색 / 글자 크기 / 카드 모양 / 흐름 중 무엇).
- Claude는 받은 캡처에서 레이아웃 그리드, 여백 리듬, 타이포 계층, 색 역할, 카드 형태를
  뽑아 우리 언어로 옮긴다. 이미지를 베끼지 않고 **구조만** 가져온다(저작권).

## 4. 쓸 수 있는 디자인 스킬 (2026-09-03 확인)

`taste` 스킬은 이 계정에 **없다**. 실제로 있는 것:

| 스킬 | 용도 |
|---|---|
| `artifact-capabilities` | **핵심** — 페이지가 데이터를 저장하고 사용자를 식별한다. 수강생 인증·진도 저장·1일 1개념 배급을 프로토타입에서 실제로 동작시킬 수 있다 |
| `artifact-design` | 아티팩트 기본기 (테마 토큰, 레이아웃) |
| `design` | 여러 화면을 캔버스에 펼쳐 직접 손보기 — 원장님이 시안을 직접 만질 수 있다 |
| `dataviz` | 성취도·오답 추이 차트 (진짜 데이터로, 이미지 차트 금지) |
| `medical-app-design` | 앱 6종 전용. 교재 서비스엔 트러스트 바·뷰티 바·구성 원칙만 차용 |
| `artifact-diagramming` | 교재 그림을 화면으로 옮길 때 |
| `canvas-design` | 홍보물·앱 아이콘 |
| `skill-creator` | **박찬 과학 전용 디자인 스킬**을 만들어 두면 매 세션 재설명이 사라진다 |

## 5. 교재에서 이어받을 디자인 언어

이미 완성된 교재가 서비스의 정체성이다. 새로 만들지 말고 확장한다.

- 단원 색: I 테라코타 `#C1521E` · II 딥틸 `#147D6F` · III 인디고 `#4053B8`
- 타이포: Noto Sans KR 본문, 숫자는 tabular-nums
- 구조 언어: 뼈대 3걸음 → 큰 그림 → 그림 읽는 법 → 본문 → 용어 → 오해✗진실✓ → 포인트
- 화면당 히어로 1개, 나열식 금지 — 교재의 "개념 하나에 두 쪽" 원칙을 화면에 옮긴다
