## 1. 자체 검수 1차 — 화면(2026-10-13)
방법: `tools/review_pack.py` 로 검수용 예시 기록(9일 사용)을 넣은 앱 화면 37장을 찍고, 세 묶음(처음 온 사람·학생 / 학생 / 보호자·원장)을 나눠 보게 한 뒤 하나씩 화면·코드로 확인.

### 틀림(찍는 방식 때문) — 고치지 않음
- 정답률·개념 수·리듬이 화면마다 다름(7 vs 8, 1/7 vs 2/7): 찍는 스크립트가 한 창에서는 오늘 개념을 읽고 다른 창에서는 안 읽어서. 정답률 84 %(문제 은행 문항별 마지막 답) vs 69 %(모든 풀이)는 서로 다른 지표 — 라벨은 '지금까지 정답률'로 밝힘
- 탭 바가 화면 가운데를 가림: 긴 화면 통째 캡처에 고정 탭 바가 찍힌 것(실제 화면은 아래 여백 있음)
- 날짜 입력이 '10/13/2026': 찍는 브라우저가 영어 설정이라서(PDF 는 이제 한국어 설정으로 찍음)
- 원장 확인 창이 없다: 반 삭제·코드 해제·보호자 연결 해제 모두 확인 창이 있다

- 워터마크 '박○○ · stu***' — 세 묶음 모두 '진하고 감시받는 느낌'이라 함. 캡처 억제력과 바꿈(디자인 #11)
- 12개월권 '인기' 표시 — 판매 기록 전에는 '사실이 아닌 강조'로 보일 수 있다는 지적(2026-10-12 원장님이 '인기'로 정함)
- 홈에 카드가 많음(공지·과제·시험·경로·리듬·노트·명언) — 홈 C '하루 경로'는 원장님 결정. 명언 카드는 줄일 수 있음
