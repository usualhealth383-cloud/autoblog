# 학원 홍보물 원본 (2026-09-29 원장님 전달)

나중에 홍보물을 만들 때 찾아오는 자리입니다. **지금 이걸로 무엇을 만들라는 뜻은 아닙니다.**

| 파일 | 무엇 |
|---|---|
| `x배너-A.webp` | 실내 X배너 — 하늘색 그라데이션, 개설강의 4줄(고1 예비·고1 내신·고3 수능·중등부 특강), 강점 3줄, 전화 |
| `x배너-B.webp` | 위와 같은 구성의 다른 버전 |
| `포스터-전단.webp` | 포스터/전단 — 개설 강좌 2×2, 강점 3칸, 하단 남색 띠에 상담문의·5층·전화 |
| `현수막-가로.webp` | 가로 현수막 — 남색 바탕 + 금색, 하단에 전화와 반 이름 알약 |
| (미확보) | 외부 간판·창문 시트지 — 회색 바탕, '박찬'(파랑)+'통합과학 학원'(흰색), 남색 태그 4개와 노란 전화번호. 대화에는 있으나 파일이 오지 않아 저장하지 못했습니다 |

## 실제 쓰이는 색 (이미지에서 뽑음)

| 쓰임 | 값 |
|---|---|
| 밝은 파랑 (로고 '박찬', 강조) | 대략 `#0054F0` ~ `#003CE4` |
| 남색 (본문·바탕·태그) | 대략 `#003C9C` · `#00183C` · `#000C3C` |
| 하늘색 바탕 | `#CCE4FC` ~ `#E5F3FE` |
| 금색 (현수막·간판 전화번호) | 노랑 계열 |

## 기억해 둘 것 — 앱 색과 다릅니다

앱은 딥틸 `#147D6F` 를 브랜드 색으로 씁니다. 반면 간판·현수막·배너는 **파랑/남색 + 금색**입니다.
학생이 간판을 보고 앱을 열면 같은 학원으로 보이지 않습니다.

나중에 정할 일(지금 결정하지 않음)
1. 앱을 간판 색(파랑/남색)에 맞출지 — 앱 아이콘·토큰·스크린샷을 다시 만들어야 합니다
2. 간판을 앱 색(딥틸)에 맞출지 — 이미 제작한 실물이 있어 비용이 듭니다
3. 둘을 의도적으로 나눌지 — 그렇다면 앱 안에 학원 로고를 넣어 잇는 장치가 필요합니다

앱 색 토큰은 `app/app-shell.html` 맨 위 `--brand` 한 줄이라 바꾸는 일 자체는 작습니다.
다만 아이콘(`app/icons/`)과 스토어 스크린샷(`store/screenshots/`)을 다시 만들어야 합니다.
둘 다 `tools/make_icons.py` · `tools/store_shots.py` 로 자동 생성됩니다.
