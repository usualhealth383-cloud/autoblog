### 2.3 The repeating rhythm
**Each concept chunk is 1–2 pages and is followed immediately by a 1-page 개념 확인 문제.** That makes two concept-plus-check cycles per 소단원. Then come 비법 특강 (optional), 내신 만점 (3–4 pp) and 실력 UP (1 p). The publisher's 구성과 특징 names the stages "01 단원 핵심 내용 파악하기, 02 내신 문제 적용하기, 03 반복 학습으로 실력 다지기" (B1).

### 2.4 Concept-page elements (`tg1_t3–t4`, `tg2_t3–t4`, zooms `z_t3_*`, `z_t4_*`, `z2_t3_left`, `z2_t4_right`)

**Main column (about 75% of the width)**
- **Hierarchy:** the 소단원 numeral is followed by a circled section letter (A, B, C…) with a title bar, then numbered bold items (1., 2.), then circled sub-points (①, ②). Each statement is followed by "⇒" consequences and "예" examples.
- **첨삭:** short magenta/pink handwritten-style notes hang off a phrase with a "↳" hook arrow, like a tutor's marginal correction. There are usually 1–3 per page.
- **Figure call-outs:** light-blue rounded "speech" boxes sit near figures and narrate a process step. Some figures have small pink/red labels with arrows.
- **Markers:** a red **\*** after a term means it is glossed in the wing. A superscript numbered ❶ means it is etymologized in the wing's 용어 list.
- **Figure captions:** each caption is preceded by a small hollow "○" ring icon.
- **"탐구 자료창":** a dotted-border rounded panel with a cloud-shaped label tab. It sets a textbook experiment or data set on the left and a numbered step-by-step interpretation on the right: 1. observation, 2. comparison, 3. 결론. One appeared per concept spread in both samples.

**Wing column (outer margin, about 22% of the width)**

| Wing element | Look | Function (paraphrased) |
|---|---|---|
| **✦ (red diamond) term notes** | Bold red-diamond heading with 3–6 lines; often a small photo or diagram whose own caption is a magenta ↳ note | Glosses the terms starred in the main text |
| **주의해** | Orange flag tab | Pitfalls. In one observed case (p.32) it is a small table comparing how **different 교과서 publishers name or classify the same concept**. Reviewer B3 calls this "교과서별 비교 자료". |
| **궁금해** | Blue/purple flag tab | A "why…?" question in bold, then a short answer |
| **암기해** | Green flag tab | A one-line memorization nugget (e.g. a ratio) |
| **확대경** | Green pill with a "+" icon | Enrichment beyond the core. The name comes from the 구성과 특징 text in B1; the label in the previews is too small to read reliably. |
| **용어** | Teal heading with a rule line, always at the bottom of the wing | Numbered term list with 한자 breakdown (e.g. "X(漢 뜻, 漢 뜻)" then a definition) |

Density: each concept page has about 3–5 wing items, so the wing is nearly full.

## 3. Unit-level structure

Every 중단원 has three closing parts:

**1. 중단원 핵심 정리**
- 1 page for a 2-소단원 중단원 (p.56), 2 pages for 3 소단원 (vol.2 pp.42–43), 3 pages for 5 소단원 (pp.112–114, `st_8.jpg`).
- Format: two columns. Each 소단원 gets an outlined "01 / title" banner, then numbered headings.
- Most content is in **compact tables** (구분 | 특징 | 예), arrow chains and small schematic figures, with **numbered blanks** (❶❷… in tinted pills) that the student fills in. It is a retrieval exercise, not a passive summary.

**2. 중단원 마무리 문제**
- About 4–5 pages (pp.57–60; pp.115–119; vol.2 pp.44–47 **[est.]**), with 4–6 items per page, so **[est.] about 16–25 items**.
- Mixes 합답형, plain 5지, matching-table 5지 and **서술형 items flagged with a red "서술형" tag**. There were 2 서술형 among the first 6 items of vol.2 p.44.
- Each item carries ●-dot difficulty.

**3. 중단원 고난도 문제**
- Purple header. 4 items on the first page (pp.61, 120; vol.2 p.49). Length 1–2 pages **[unverified exactly]**.
- All observed items are [보기] 합답형 that combine two data sources: a table plus a periodic-table fragment, two cross-sections, a radar chart, or a phylogeny plus a graph.

**No 대단원 평가.** The 구성과 특징 in B1 lists only 중단원-level closers, and no 대단원 test page appears in any preview. So the book closes at the 중단원 level only. **[Absence verified only via the 구성 description and the previews.]**

**수능 미리보기** (separate booklet; 48 pp vol.1, 36 pp vol.2), for each 중단원:
- **"수능 빈출 자료 분석하기"** (green header):
  - "이 단원의 수능 빈출 자료 ①, ②": one sentence on what the 수능 asks about this data.
  - Then one data figure with **5 OX statements**.
  - The margin gives a **source tag**, e.g. "2023학년도 9월 모평 … 7번 변형" or "2025학년도 6월 모평 … 20번 변형" (`tg2_t16`; the 2024학년도 수능 and 9월 모평 tags are in `st_12.jpg`).
  - The margin also has "연관 개념 → 본책 13쪽" back-references.
- **"수능 문제 도전하기"** (blue header): two 5지 합답형 items per page. A tinted footer under each item gives **"출제 의도"** (one line) and **"연관 개념 → page"**.

**2028 예시문항.** I found no evidence that the book contains or labels the 2028 수능 통합과학 예시문항 in any preview, publisher page or review. The 수능 section is built from **existing 모평/수능 items (e.g. 지구과학Ⅰ, 생명과학Ⅰ) marked "변형"**. **[Whether 예시문항 appear elsewhere in the 48 pages: unverified.]**

## 4. 해설 (정답친해) format
Sources: `tg1_t13–t14`, `tg2_t13–t14`, zooms `z_ans1_*`, `z_ans2b_*`.
- **Layout:** two columns. Each problem set opens with a colored header bar in the same color as its 본책 section (teal for 개념 확인, pink for 내신 만점, orange for 비법 특강). The bar shows the 본책 page range (e.g. "17쪽~20쪽").
- **Answer grid:** directly under the header is a tinted **answer grid** with all answers of the set, for fast self-grading. For 개념 확인, the grid also includes the 핵심 체크 blank answers.
- **Per-item explanation:**
  - It first explains why the correct choice or choices are right.
  - Every wrong choice or statement then gets a **"바로알기"** pill tag (blue outline), and the false statement is **rewritten as a true one**, not just marked false.
  - So all 5 choices or all ㄱㄴㄷ are addressed.
- **"꼼꼼 문제 분석":**
  - A dashed rounded box that **redraws the problem's figure** (e.g. a graph) with brown curved arrows to short notes.
  - Each note says what each region or point means and what follows from it.
  - It appears on data-heavy items: 1 of 7 items on the observed page.
- **서술형:**
  - A "모범 답안" pill, then a **채점 기준 table** with partial credit.
  - Two rows in the observed case: 100% for full, 50% for partial.
- **Cross-reference:** every 본책 problem page has "✎ 정답친해 N쪽" at the top right, so the solution page is one lookup away.
- **Length:** 104 pages for 224 본책 pages. Reviewers say 완자's 해설 is more detailed than 오투's (B8 pathos_z), and that it is "그림 + 과정 설명" (B3 january, a sponsored review).

## 5. Page design

**Grid**
- Concept pages: a main text column plus one outer wing column (about 75/22), separated by a thin gray vertical rule.
- Problem pages: two equal columns with a vertical rule.
- 정답친해: two columns.
- Trim size is 210×265, shorter than A4, so pages feel compact.

**Color system**
- Each section type has its own header color and a big-type header with a mascot vignette:

| Section | Header color |
|---|---|
| 개념 확인 | teal |
| 비법 특강 | orange |
| 내신 만점 | pink/red |
| 실력 UP | green |
| 중단원 핵심 정리 | teal and blue |
| 중단원 마무리 | blue-violet |
| 고난도 | purple |
| 수능 빈출 자료 | green |
| 수능 도전 | blue |

- Body accent colors: navy for section letters, red/magenta for 첨삭 and term markers, orange/blue/green for the wing flags.
- Openers are pastel full-bleed (blue/teal).

**Typography**
- Headers are a heavy rounded gothic display face.
- Problem stems are bold gothic. [보기] contents and choices are a serif (명조-style) face (`st_7.jpg`, `st_9.jpg`).
- 첨삭 uses a smaller colored face.
- Body text is about 9–10 pt **[est.]**, wing text about 7–8 pt **[est.]**.

**Figures**
- Mostly **full-color illustrations**: semi-3D atoms and particles, spectra drawn as gradient bars, cross-sections, process strips.
- Plus **real photos** for fossils, nebulae and minerals, and clean line graphs.
- Photos are small and placed inside tables, e.g. a fossil-photo table with 환경/시기 columns.
- Annotation style: thin colored leader lines to labels, pink arrow notes, and blue rounded call-out boxes.
- **Problem figures are also full color**, unlike 완자 기출PICK, whose figures are black-and-white to match school exams (B10 dc_eduplex: https://blog.naver.com/dc_eduplex/224227979421).

**Density**
- High. Concept pages are almost fully covered by body text, tables, a figure and 3–5 wing boxes.
- Problem pages hold about 4–6 items.

**Character branding**: a recurring mascot set (cat, dog, raccoon-like) appears on openers, section headers and 정답친해. It is light and does not take content space.

  - Many 학원 lecturers use it (V1 student review, 2026-05-02).
  - A 학원 uses it as its external base text plus its own worksheets (B7 promise240201: https://blog.naver.com/promise240201/224400732353).

### Complaints and limits
- **Passive-reading risk.**
  - Because explanations are dense and the 개념 확인 comes right after reading, students can answer from short-term memory and feel they understand.
  - B4 formare_lab (https://blog.naver.com/formare_lab/224349497677) advises closing the book and re-explaining, re-testing on day 2 and day 7, and transferring to other data. It places 완자 for 3–5등급 students whose concept links are broken.
- **Length and time.** At 376 pp, B8 recommends 오투 instead for 상위권 who need time for other subjects.
  - One 예비고1 needed about 10 months for one pass of 통합과학1, found the later units "너무 어렵다", and relied on 인강. Some 중단원 마무리 items were not covered by the chosen 인강 (B12 eblue7: https://blog.naver.com/eblue7/224161879817).
- **Not enough drill on its own.** Reviewers routinely pair it with 완자 기출PICK (1080제 for vol.1, 764제 for vol.2) for problem volume (V1 student review, 2026-02-16; B11; B9).
- **Errors and stale material.** An experienced lecturer says 비상 books are revised every year, yet problem errors and "성급하게 낸 문제" still show up. The same lecturer says the free downloadable materials are old and not revised (B13 kelld: https://blog.naver.com/kelld/223457122697, 2024, updated 2025-11). B13 also rates 완자 분량 ★4/5 and 종합 ★3/5.
- **Textbook mismatch** (older-curriculum review): because 통합과학 content differs by textbook publisher, a 2019 reviewer advised buying the school-publisher 자습서 first (B14 zenhoo: https://blog.naver.com/zenhoo/221749403313). The current edition partly answers this with "주의해" textbook-comparison boxes (seen p.32; B3 mentions "교과서별 비교 자료").
- Excluded: https://blog.naver.com/ewzgyhyanh198044/224379917695 has fabricated-looking claims (lab equipment, a "4부제" and "5 volumes"). It looks auto-generated, so I did not use it.

## 7. 우리 책이 배울 것 (구체적·실행 가능한 항목)

1. **Close every concept chunk with a 1-page check, not just the 소단원.**
   - Split each 소단원 into 2 concept blocks of 1–2 pages each.
   - Place a check block of 4–8 items immediately after each block, so there are 2 per 소단원.
   - Mix the item types: matching, (1)(2)(3) OX, 빈칸 ㉠㉡, ordering, [보기] choice.
   - Evidence: §2.1–2.2, pp.11/13 and 12/15.
2. **Open each check block with a "핵심 체크" blank-fill strip** of 4–5 lines with numbered blanks, and put the answers in the answer key's first row.
   - HTML: a `<div class="core-check">` with `<span class="blank" data-n="1">` elements, plus a reveal toggle.
   - Evidence: `tg1_t5`, `z_ans1_left`.
3. **Add a 소단원 "핵심 포인트" box with importance ratings.**
   - Put 4–5 bullet points at the 소단원 start, each tagged ★★ or ★★★, and reuse the same point names as the A/B/C section titles.
   - Evidence: `z_t3_point.jpg`.
4. **Use a fixed outer-wing column (about 22% width) with exactly 5 named box types and fixed colors.**
   - The types: 주의해 (pitfall), 궁금해 (why-question), 암기해 (one-line fact), 확대경 (enrichment), and 용어 (한자 etymology, always at the bottom).
   - Link each red `*` or `❶` marker in the body to its wing entry. In HTML, use `aside` elements anchored to paragraphs; on narrow screens the wing collapses inline under the paragraph.
   - Evidence: §2.4.
5. **Include a "교과서별 차이" pitfall table** wherever 2022 textbooks differ in a term or classification.
   - A 3-row table: publisher group, then how it is named.
   - This directly answers the most common criticism of 시중 문제집 (B14) and is a 완자 differentiator (p.32 주의해; B3).
6. **Add 첨삭-style margin notes inside the body.** Allow at most 3 per page: short pink notes with a `↳` hook attached to a specific phrase, to state the hidden step or the classic misreading.
   - HTML/CSS: an inline `<span class="annot">` with `::before { content:"↳" }` in an accent color.
   - Evidence: `tg1_t3–t4`.
7. **Every textbook experiment gets a "탐구 자료창" panel in a fixed 3-step format.**
   - Left: a data figure. Right: 1. 관찰 → 2. 비교 → 3. 결론.
   - Use a dotted border with a tab label.
   - Evidence: `z_t4_tamgu.jpg`, `tg2_t3`.
8. **Add a 1-page "비법 특강" synthesis only where the 소단원 has a process or timeline.**
   - Structure: 1 big chart plus 1 table, then 1–2 "Q." check questions, one of which is 서술형 with a 채점 기준 in the key.
   - Skip it for short 소단원; 완자 omits it in Ⅰ-1-01.
   - Evidence: pp.16 and 39, `st_5.jpg`.
9. **Set problem counts per 소단원:**
   - 내신 18–24 items, grouped by the A/B concept letters, with 2–4 서술형 grouped at the end.
   - 심화 4 items, all multi-source [보기] 합답형.
   - Flag must-do items with a "중요" stamp.
   - Evidence: §2.5 answer grids.
10. **Put per-item difficulty dots (●○○/●●○/●●●) on 중단원-level sets**, with a legend chip next to the section title, and a red "서술형" tag above 서술형 items. In HTML, use a `data-level="1..3"` attribute styled with CSS dots.
    - Evidence: `tg1_t10`, `st_9.jpg`.
11. **Make the 중단원 summary a blank-fill table sheet, not prose.**
    - Two columns, one banner per 소단원, mostly 구분|특징|예 tables and arrow chains, with numbered blanks.
    - Size: about 1 page per 2 소단원.
    - Evidence: p.56, pp.112–114 (`st_8.jpg`).
12. **Write answer-key entries that address every choice.**
    - Open with an answer grid per set, showing the source page range in the header bar and using the set's color.
    - Then, per item: why the correct choice is correct, followed by a "바로알기" tag for each wrong statement **rewritten as the true statement**.
    - Evidence: `z_ans2b_left.jpg`.
13. **Add a "꼼꼼 문제 분석" redraw for data-heavy items.**
    - In the solution, re-render the problem's graph with 2–4 arrowed annotations. With SVG this is cheap: reuse the problem SVG and add a `<g class="analysis">` layer.
    - Aim for about 1 in 6 items.
    - Evidence: `z_ans2b_right.jpg`.
14. **Cross-link both ways.**
    - Each problem page shows "해설 N쪽" at the top right.
    - Each 수능-type item shows "연관 개념 → N쪽" and a one-line "출제 의도".
    - In HTML these are real anchors.
    - Evidence: `tg1_t8`, `tg2_t16–t17`, `tg1_t17`.
15. **Start each 대단원 with a "학습 연계" page.**
    - Middle-school prerequisites as 5–8 blanks with the answers in a footer strip, plus a list of the concepts in this unit.
    - Add a 수능-preview section per 중단원 in the format 빈출 자료 + 5 OX statements + 2 합답형 items. Unlike 완자, which relies on old 모평 "변형" items, label which items follow the **2028 예시문항 style**; this is a gap our book can fill.
    - Evidence: `tg1_t2`, `tg2_t2`, §3.

Design guardrails drawn from the complaints:
- Add a spaced re-check, e.g. a "2일 뒤 다시" 3-item mini-quiz at the start of the next 소단원, to counter the passive-reading risk (B4).
- Keep the 본책 lean (완자 is criticized as long; B8, B12).
- Publish a 정오표 page, since errors are the main trust complaint about this publisher (B13).
