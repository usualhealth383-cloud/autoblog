# 공부 노트 조사 — 기록을 꾸준히 하게 만드는 것 (2026-10-07)

> 원장님 요청(2026-10-07): "더 기록하고 싶은 형태로 노트 쓰기 란을 보완해도 좋겠어."
> 범위: 공부 노트의 **쓰기 화면**과 **노트 보기**. 사적인 공간(원장·보호자 안 봄)이라는 정책은 그대로 둔다.
> 표기: [1차] = 회사·저자 원문을 직접 열어 확인, [2차] = 리뷰·요약 글, [못 찾음] = 찾아봤지만 확인하지 못함. 확인한 것만 적었다.

## 3. 설계 원칙 → 화면

1. **빈 칸 공포 없애기** — 첫 칸 안내가 그날 배운 개념 이름으로 바뀐다(「원소의 주기성」에서 떠오르는 것 하나). 칸 위 **끼워 넣기 칩**: 오늘의 개념 · 빈칸 ㉠㉡㉢ 단서 · 오늘 틀린 문제. 누르면 지금 쓰는 칸에 들어간다(코넬 '질문' 칸이면 빈칸 문장을 ( ㉠ ) 질문 꼴로).
2. **1분이 기본, 더 쓰고 싶으면 펼침** — 틀 4개: 세 줄 요약(기본) · 코넬(질문/핵심/요약) · 헷갈린 것 하나(헷갈렸던 것 → 이제 아는 것) · 자유. 제목·메모는 '더 쓰기'를 눌렀을 때만. 글자 수 표시 없음.
3. **인출 먼저, 확인은 뒤에** — '책을 덮고 먼저' → '교재와 견주기'(붙인 개념의 포인트·①②③ 제목).
4. **시험 전날 다시 읽고 싶은 모양** — 틀마다 카드 모양이 다르다(세 줄 번호 · 코넬 2단+요약 · 헷갈림→앎). '시험 전 다시 읽기'는 소단원별로 모으고, 질문만 보이게 가려 두었다 눌러서 확인(코넬 암송).
5. **되돌아보기** — 오늘 화면에 '지난주 오늘 · 2주 전 오늘 · 한 달 전 오늘' 가운데 있는 한 장. 노트에서 '같은 소단원 노트 n개'.
6. **차분함** — 마음 다섯 단어(뿌듯 · 차분 · 그럭저럭 · 지침 · 막막)와 이해 3단계(아직 흐려요 · 반쯤 잡혔어요 · 설명할 수 있어요)는 **선택**, 다시 누르면 풀림. 스티커·이모지·연속 일수·색종이 없음. 완료하면 한 줄 "남겨 뒀어요 · 이번 달 n번째 기록".
7. **사적인 공간** — 원장·보호자 안 봄(서버 RLS 그대로, 새 칸도 본인만). 화면 끝 '노트는 나만 봅니다' 그대로.

## 4. 하지 않은 것(과 까닭)
- 사진 붙이기: 처리방침 ⑫ '사진을 수집하지 않습니다'와 부딪힌다 — 원장님 판단 전에는 넣지 않는다.
- 기분 통계·그래프: 하루콩·Daylio 의 핵심이지만 학습 앱에서 마음을 숫자로 보여 주면 감시처럼 느껴질 수 있다 — 달력·카드에 단어로만.
- 연속 기록 일수: 앱 원칙(쉬는 날을 탓하지 않는다)과 같이 세지 않는다.
