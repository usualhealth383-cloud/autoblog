# 자체 제작 음악 플레이리스트 채널 — 기획안 v1

> 작성 2026-10-06 · 상태: **기획안. Suno 결제와 채널 개설 전**

## 1. 결론

- **방향:** 기존 곡은 쓰지 않습니다. **Suno 유료 플랜으로 만든 자작곡**에 **의사의 큐레이션**을 더한 플레이리스트 채널입니다.
- **1순위 콘셉트(추천):** "의사가 설계한 수면 음악". 가사 없는 연주곡이라 전 세계 어디서나 들을 수 있고, 긴 영상이라 수익화 조건인 시청 시간 4,000시간을 빨리 채울 수 있습니다.
- **차별점:** 이 분야 1등 채널(수면·로파이)은 분위기 좋은 영상과 음악을 꾸준히 올리는 데서 멈춥니다. 우리는 **근거 기반 설계**(Cochrane 리뷰의 청취 시간, 점점 느려지는 곡 구성, 갑작스러운 자극 배제)와 **의사 큐레이터라는 신뢰**로 앞서 나갑니다. 따라 하기 어려운 차별점입니다.

## 2. 콘셉트 후보 (현욱님 선택)

| | A. 수면 처방 음악 ⭐추천 | B. 한국어 보컬 감성 플리 | C. 가톨릭 묵상 음악 |
|---|---|---|---|
| 대상 | 전 세계 (가사 없음) | 한국, 20~40대 | 신자 (가톨릭한스푼 연계) |
| 영상 길이 | 1~3시간 | 30~60분 | 30~60분 |
| 시청 시간 누적 | 매우 빠름 | 보통 | 보통 |
| 경쟁 | 높음. 단, 의사 큐레이션 채널은 거의 없음 | 매우 높음 (AI 보컬 홍수) | 낮음 |
| 정책 위험 | 낮음 (기획·서사가 명확할 때) | AI 보컬 대량생산으로 보일 위험 | 낮음 |
| 차별점 | 의학 근거 + 의사 | 가사 품질 | 신앙 진정성 |

A로 시작하고, 3개월 뒤 C를 서브 채널로 붙이는 방식을 추천합니다.

## 3. 근거 (PubMed)

- **성인 불면에 음악 듣기 (Cochrane 2022, 13개 연구, 1,007명):** 매일 녹음된 음악을 **25~60분** 들었을 때 주관적 수면의 질이 좋아졌습니다. 근거 수준은 중등도(moderate)로, 수면의 질 지표(PSQI) 평균차는 −2.79점입니다. 반면 수면다원검사 같은 객관적 측정에서는 개선이 확인되지 않았습니다. [DOI](https://doi.org/10.1002/14651858.CD010459.pub3)
- **임신 중 불면 (2025 메타분석, 무작위 대조시험 4건, 348명):** 취침 전 음악이 수면 문제를 줄였습니다(평균차 −1.38). 다만 연구들의 비뚤림 위험이 높습니다. [DOI](https://doi.org/10.1016/j.midw.2025.104294)
- **수술 전 불안 (Cochrane 2013, 26개 연구, 2,051명):** 음악을 들으면 불안 척도(STAI-S)가 5.72점 더 낮아졌습니다. [DOI](https://doi.org/10.1002/14651858.CD006908.pub2) 진료 대기실·수술 전 플레이리스트의 근거로 쓸 수 있습니다.
- **템포:** 흔히 "60~80 BPM"을 권하지만, 특정 템포의 효과를 직접 입증한 근거는 **[확인 필요]**입니다. 영상과 설명에서는 "근거 기반"이라고 쓰지 않고 "설계 원칙"이라고만 표기합니다.
- **표현 수위:** "불면 치료"나 "처방" 같은 효능 주장은 하지 않습니다. "수면 루틴을 돕는 음악"으로 쓰고, 면책 문구는 1줄만 넣습니다.

## 4. 유튜브 정책 체크리스트 (2026-07-15 개정 반영)

1. **재사용·비진정성 콘텐츠:** Suno 결과물을 그대로 쏟아내면 탈락합니다. 그래서 다음을 지킵니다.
   - 회차마다 고유한 기획(주제·서사)을 둡니다.
   - 사람이 곡을 고르고 순서를 정합니다.
   - 커버 아트를 직접 만듭니다.
   - 의사 큐레이터 노트를 넣습니다. 설명란과 영상 첫 화면에 "오늘의 설계 의도" 3줄을 씁니다.
2. **AI 표시:** 업로드할 때 "변경되거나 합성된 콘텐츠" 항목을 켜고, 설명란에 "음악은 AI 도구로 제작"이라고 밝힙니다. 의무 범위는 [확인 필요]지만 켜는 쪽이 안전합니다.
3. **Content ID:** 자작곡이므로 타인에게 수익이 넘어갈 위험은 없습니다. 단, **무료 계정으로 만든 곡은 절대 사용 금지**입니다(상업 이용 불가, 소급 적용 안 됨).
4. **업로드 속도:** 한꺼번에 많이 올리면 대량생산 신호로 보입니다. **주 2회**를 상한으로 둡니다.

## 5. 비용·수익 (정직한 추정)

| 항목 | 금액 |
|---|---|
| Suno Pro | 월 $10 (약 1.4만 원). 월 2,500크레딧, 약 500곡. 상업 이용 가능 |
| Suno Premier | 월 $30. 음원 분리·MIDI가 필요할 때만. 지금은 불필요 |

| 영상 합성 | 무료 (`build_playlist.py`, ffmpeg) |

- **수익화 조건:** 구독자 1,000명과 최근 12개월 시청 4,000시간이 필요합니다.
- **조회수당 수익(RPM):** 1,000회당 일반적으로 $1~5이고, 휴식·음악 분야는 낮은 편입니다.
  예를 들어 월 10만 회 × RPM $2 = **월 약 $200(약 28만 원)**입니다.
- **현실적 기대치:** 초기 3~6개월은 수익이 0원에 가깝습니다. 수익은 영상이 쌓이면서 생기는 누적 자산형입니다.

## 6. 제작 파이프라인 (1회차 약 1시간)

1. **기획 (Claude):** 회차 키트를 작성합니다. 콘셉트, 곡별 Suno 지시문, 제목, 설명, 썸네일 지시문이 들어갑니다. → `playlist/001_*.md`
2. **곡 생성 (현욱님 또는 자동화):** Suno에서 곡당 2버전이 나오면 더 좋은 쪽을 고릅니다. 파일명은 `01_제목.mp3` 형식으로 저장합니다.
3. **커버 (Gemini):** 키트에 있는 프롬프트로 16:9 이미지 1장을 만듭니다.
4. **합성:** `python build_playlist.py --tracks ... --image ... --out ... --repeat 4` → mp4와 챕터 텍스트가 나옵니다.
5. **업로드:** 키트의 제목과 설명에 챕터를 붙여 올리고, AI 표시를 켭니다. 공개 전에 현욱님이 최종 확인합니다.

> 나중에 자동화: 2번 곡 생성은 Suno 공식 API가 없어 아직 수동입니다. 4~5번은 제작 PC 스케줄러(요즘건강 파이프라인)에 붙일 수 있습니다.
