# 약지도 — 증상에 맞는 약, 의사가 고르듯

> 증상을 고르면 진료실에서 처방하듯 **진통·소염·근이완·위보호** 조합으로 풀어 주고,
> 약국(또는 편의점)에서 무엇을 사면 되는지, 왜 그 성분인지, 언제 병원에 가야 하는지를 알려주는 앱.
> 약 정보(성분 기준)·같은 계열 비교(위장 vs 심혈관 부담)·영양제 성분 비교(제형·유효용량·상한)까지 한 곳에.

- 배포: `https://usualhealth383-cloud.github.io/autoblog/yakjido/` (GitHub Pages, PWA)
- 소스: `yakjido/app-shell.html`(단일 파일 앱) + `yakjido/content/*.json`(콘텐츠) → `python3 yakjido/tools/build.py` → `docs/yakjido/`
- 검수: 내과 전문의(박현욱) · 모든 임상 수치는 `content/sources.json`에 근거 등록. 근거 없는 값은 `[확인 필요]`로만 표기.

## 1. 벤치마크 + 차별점 (한 줄)

**이 분야 1등(Drugs.com·NHS Medicines A–Z·GoodRx)은 "약 이름 → 정보"와 "증상 → 응급도"를 잘 한다 → 우리는 그 사이의 빈칸, "증상 → 의사가 짜는 성분 조합 → 약국 장바구니"를 근거와 함께 채운다.**

리서치(`/scratchpad/research/01-apps-benchmark.md`, 20여 개 앱)에서 확인한, 아무도 제대로 하지 않는 것:

| # | 빈칸 | 약지도의 답 |
|---|---|---|
| 1 | 증상 체커는 "병원 가세요"에서 끝남. 파미·이아소는 제품 1개만 찍어 줌 | **처방 스타일 조합 카드**: 슬롯(진통·소염·근이완·위보호)마다 "왜", 일반약 대안, 처방 필요 여부 |
| 2 | 계열 안 비교(어느 소염제가 위장에 덜 부담?)는 블로그 글뿐 | **위장×심혈관 부담 산점도**(CNT 2013·Castellsague 2012 상대위험을 코드로 그림) + 상황별 결론 |
| 3 | 임신·위궤양·항응고제 같은 개인 조건으로 구매 전 걸러 주는 앱 없음 | **내 정보** 11개 스위치 → 추천·상세에 "내 정보 주의" 자동 표시(기기 내 저장) |
| 4 | 감기약 속 아세트아미노펜 + 타이레놀 중복을 잡아 주는 앱 없음 | **내 약통** 중복 성분 검사(복합제 `contains` 기반, NSAID 이중 복용 경고) |
| 5 | 영양제 앱은 인기순·최저가만. 제형·유효용량·₩/유효용량 없음 | **성분 비교 + 계산기**: 함량÷임상 유효용량 %, 유효용량 1회분 가격, 상한(UL) 경고 |

## 2. 디자인 방향 (medical-app-design 스킬 §3 브리프)

- **참고한 앱:** Drugs.com, NHS Medicines A–Z·care cards, GoodRx, Medisafe, 약학정보원, e약은요, 필리·필라이즈 — 공통점: 검색창 하나가 홈, 약 페이지 섹션 순서 고정, 검수자·날짜·출처 노출, 심각도는 색+글자.
- **팔레트:** primary `#0B6E8F`(딥 틸블루, NHS 블루와 Medisafe 틸 사이, 흰 바탕 5.9:1) · 바탕 `#FAF8F3`(GoodRx식 따뜻한 오프화이트 — 병원 서류 회색 금지) · 카드 `#FFF` + 헤어라인 `#E6E2DA` · 정상/주의/응급 = NHS 계열 초록·앰버·빨강(항상 글자와 함께) · 처방약은 보라빛 `#4C5FB5`로 구분. 국내 경쟁 앱(필라이즈·닥터나우)의 보라·코랄과 반대편이라 매대에서도 구분됨.
- **타이포:** 본문 Noto Sans KR(웹폰트 링크, Pretendard 있으면 승격) · 히어로 인사말 한 줄만 Gowun Batang · keep-all · 숫자 tabular.
- **레이아웃:** 탭 4개(증상·약 사전·영양제·내 정보). 홈 = 인사말 + 검색 + 증상 타일. 증상 화면의 히어로는 **처방 카드 1개**, 나머지는 계층 아래로.
- **신뢰 장치(조용한 볼륨):** 상단 "전문의 검수 · 2026-09" 스탬프 1개, 근거는 출처 칩 한 줄, 화면당 면책 1개(맨 아래), 위기 경로는 3단계 케어 카드(약국 / 병원 / 119)로 필요한 곳에만.
- **시그니처:** 처방전을 닮은 조합 카드(점선 헤더 + 기울어진 검수 도장). 두 번째: 계열 비교 산점도.
- **의도적으로 피한 것:** 캐릭터·일러스트(약 정보에는 유치함이 곧 불신), 빨강 남발, 기능 나열식 홈, 브랜드명 우선(성분 우선 원칙).
