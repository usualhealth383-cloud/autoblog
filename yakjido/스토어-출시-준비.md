결론: **앱 자체는 준비됨. 막힌 것은 현욱님이 정하실 것 4개**(개발자 계정 종류 · 사업자명 · 서명 키 · 시험 참가자 12명).

## 2. 구글 플레이 정책 대조

| 정책 | 약지도 상태 |
|---|---|
| 건강 앱 신고서(Health apps declaration) — 모든 앱 필수 | 해당 항목: **복약 알림·약 관리**, 건강 정보 제공. 의료기기 아님으로 신고 [확인 필요: 국내 식약처 판단 — 일반 건강관리(웰니스) 범주로 보는 근거 정리 필요] |

| 알림 권한(안드로이드 13+) | 첫 실행에 묻지 않고 「켜기」를 누를 때 물음 |
| 위치 | **대략 위치만**(날씨 카드 「내 위치」, 선택). 정밀 위치 권한 없음 |
| 카메라 | 권한 선언 없음 — 휴대폰 기본 카메라 앱으로 찍어 넘겨받음. 사진은 기기 안에서 글자를 읽고 서버로 보내지 않음 |
| 목표 SDK | 36 (현행 요구 충족) |

## 3. 데이터 보안(Data safety) 양식 초안

| 데이터 | 수집(기기 밖으로 나감)? | 설명 |
|---|---|---|
| 먹는 약·복용 기록·몸 상태·불편했던 약 | **아니요** | 기기에만 저장. 서버로 보내는 코드 없음 |
| 대략 위치 | 예 — **일시적 처리, 저장 안 함** | 「내 위치」를 고른 경우에만, 소수 첫째 자리(약 10 km)로 줄여 날씨 서비스(Open-Meteo)에 보냄 |
| 사진 | 아니요 | 기기 안에서 글자 읽기 |
| 기기 식별자·광고 ID | 아니요 | 광고·분석 도구 없음 |

※ 71번(사용자 기록 서버 수집)이 들어가면 이 표가 바뀝니다 — 그때 다시 씁니다.

## 4. 개인정보처리방침 초안 (공개 전 현욱님 확인 필요)

> 스토어에는 **공개 주소**가 있어야 합니다. 확인해 주시면 `docs/yakjido/privacy.html` 로 올리겠습니다(외부 공개라 지금은 올리지 않았습니다).

**약지도 개인정보처리방침**
시행일: [확인 필요] · 처리 주체: [사업자명 확인 필요] · 문의: [연락처 확인 필요]

1. **모으는 정보 — 없습니다.** 약지도에 적으신 약·복용 기록·몸 상태는 **이 휴대폰 안에만** 저장되며, 저희 서버로 보내지 않습니다. 저희는 그 내용을 볼 수 없습니다.
2. **위치** — 날씨 카드에서 「내 위치」를 고르신 경우에만 대략 위치(약 10 km 단위)를 날씨 서비스(Open-Meteo)에 보내 그날 날씨를 받아 옵니다. 저장하지 않습니다. 도시를 직접 고르시면 위치를 쓰지 않습니다.
3. **사진** — 약 사진은 휴대폰 안에서 글자를 읽는 데만 쓰고, 보내거나 저장하지 않습니다.
4. **알림** — 복용 알림은 휴대폰 자체 알람으로 울립니다. 알림 내용(약 이름)은 휴대폰 밖으로 나가지 않습니다.
5. **지우기** — 앱을 지우거나 「내 정보 → 휴대폰을 바꾸실 때 → 이 휴대폰의 기록 모두 지우기」를 누르시면 모두 사라집니다. 저희 쪽에 남는 것은 없습니다.
6. **만 14세 미만** — 보호자와 함께 쓰시길 권합니다.
7. 이 방침이 바뀌면 앱과 이 페이지에서 알려 드립니다.

## 5. 벤치마크
메디세이프는 알림·「먹었어요」·다시 알림·재고 알림·보호자 알림까지 합니다.
약지도는 보호자 자동 알림을 뺀 나머지를 모두 갖췄고, **일반약 병용 경고·어르신 주의·소아 체중 용량**은 메디세이프에 없는 차별점입니다.
또 **기록을 서버로 보내지 않는다**는 것 자체가 스토어 설명에 쓸 수 있는 강점입니다(71번 결정 전까지).
