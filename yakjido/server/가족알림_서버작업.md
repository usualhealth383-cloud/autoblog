# 가족 알림 — Main 이 할 서버 작업(11-02)

순서대로. 값(비밀)은 저장소에 적지 않는다.

1. **SQL 적용** — `yakjido/server/supabase/medinanum/메디나눔_약지도_가족알림_1102.sql`
   추가형(표 4·함수 8 · RLS 켜고 정책 없음 · anon·authenticated 표 권한 거둠). 로컬 Postgres 16 에서 두 번 돌려 같음·시험 15가지 통과.
2. **VAPID 열쇠 한 쌍 만들기** — `npx web-push generate-vapid-keys`
   - 공개 열쇠 → `yakjido/content/meta.json` 의 `familyVapid`(공개 값이라 저장소에 둬도 됨 — 약지도 세션에 알려 주면 넣음)
   - 개인 열쇠 → 아래 비밀로만
3. **Edge Function 비밀 등록**(이름만): `FAMILY_CRON_SECRET`(긴 무작위 글) · `VAPID_PUBLIC_KEY` · `VAPID_PRIVATE_KEY` · `VAPID_SUBJECT`(= `mailto:contact@medinanum.com`)
4. **함수 배포** — `yakjido/server/supabase/functions/yak-family-check/`(index.ts · logic.ts)
   `supabase functions deploy yak-family-check --no-verify-jwt` (예약 작업이 부르므로 x-cron-secret 머리글로 막음)
5. **예약 걸기** — Database → Extensions 에서 pg_cron · pg_net 켠 뒤
   `yakjido/server/supabase/medinanum/메디나눔_약지도_가족알림_예약_1102.sql` 의 `<프로젝트 주소>` · `<FAMILY_CRON_SECRET 값>` 두 자리만 바꿔 한 번 실행(파일엔 값을 넣지 않는다).
6. **켜기** — `meta.json` 의 `"family": true` + `familyVapid` 를 넣고 짓기·검사·병합(약지도 세션).
7. **확인** — 두 계정(본인·가족)으로: 본인 초대 코드 → 가족 「받은 코드 넣기」(알림 허락) → 본인 약 시간을 지금보다 2시간 15분 전으로 정하고 체크하지 않음 → 15분 안에 가족 휴대폰에 「○○ · 오전 ○:○○ 약 체크가 아직 없어요」.
   아이폰은 사파리 → 공유 → 홈 화면에 추가한 아이콘으로 열어야 알림을 받는다(iOS 16.4 이상).
