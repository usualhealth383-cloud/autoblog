# 장부 — es (원어민 확인 필요 · 숫자 예외)

## 숫자 예외 (원문과 숫자열이 다름 — 앱 숫자 틀 치환에서 빠지고 원문 그대로 일치할 때만 쓰임)
| 번호 | 원문 | 번역 | 까닭 |
|---|---|---|---|
| ui | 1만 명 중 1명 미만 | menos de 1 de cada diez mil | 「1만」을 낱말(diez mil)로 |
| ui | 1만 명 중 2명 | 2 de cada diez mil | 같음 |
| ui | Calvo 2023 … 48만 명 | … 480000 personas | 「48만」= 480000 |

## 숫자 표기
- 소수점은 원문처럼 마침표(37.5 · 1.33)로 두었다(스페인식 쉼표 소수점으로 바꾸면 앱 숫자 틀이 깨짐). 천 단위 쉼표(25,428)도 원문대로.
- 「1일 1회」(갑상선 rx.thy do[0])는 숫자 둘을 지키려고 «1 vez cada 1 día» — 어색하면 원어민 손질.
- 「아이·10대예요」→ «Es un niño o un adolescente (de 10 y tantos años)» — 숫자 지키려고 다소 어색.
- 「100명 중 N명」은 «de cada 100, N» 순서로 맞춤.

## 원어민 확인 필요
- 한국 제품 상표 로마자 표기(Geworin·Gelfos M·Pancold·Panpyrin·Penzal·Setopen·Tramol·Easyn6 등)는 공식 영문 표기를 확인하지 않고 소리대로 적었다 — 회사 영문명 확인 권장.
- 제약사 영문 법인명(Daewoo Pharm.·Samnam·Samik·Jungwoo·Taeguk 등)도 추정 표기.
- 「통화료 없음」(sym.sleep er) → «sin cargo por la llamada»: 「무료」 금지 규칙과 사실 전달 사이 — 확인.
- 「911」이 원문 ui 에 그대로 있는 문자열(911 상담·바로 911 등)은 숫자 그대로 두었다.
- 한국 고유 기관: 아이안심톡 → «Ai Ansim Talk (Corea)», 달빛어린이병원 → «hospital infantil nocturno (Corea)», 휴일지킴이약국 → «farmacia de guardia en festivos (en Corea)».
- 「dolor de barriga」(구어)를 스페인 환자 안내문 말투에 맞춰 「dolor abdominal」로 통일.
- 조각 문자열(는·를·이에요 등)은 앞뒤 문장 순서가 스페인어와 달라 자연스럽지 않을 수 있다 — 화면에서 이어 읽어 확인 필요. 조사만 있는 「가」는 빈 문자열.
- e약은요 · 약학정보원은 고유명사로 두고 「Korea Pharmaceutical Information Center」로 풀어 썼다.

## 10-28 영어 검수에서 찾은 조건 낱말 실수를 같은 눈으로 대조(응급 신호 줄)
- 「함께/또는」 범위(담관염·고열과 함께·고열·옆구리 함께)·「번지는 것은 두피 병변」·「지금 응급실」을 바로잡음. es 는 「의식 저하」(somnolencia → 의식 수준 저하)·「처음 겪는 두통」(평생 최악 → 처음 겪는)도.
- 청력·침 삼킴·마비는 이미 맞았음.

- 10-28 응급 신호 전수 자체 점검(285줄): 「감별/descartar」 → 「~일 수 있어요」 꼴, 청력 「안 돌아와요」 → 「돌아오지 않을 수 있어요」, 의식 저하·처짐 낱말 보강. 바꾼 줄은 현욱님 GPT 검수로.
- 10-28 많이 보는 증상 10편(열·두통·감기·목·기침·근골격·생리통·소화불량·설사·알레르기) 의료 이용 칸 조건 낱말 대조: ja 「넘게」를 以上(포함)→を超えて 11곳, 두통 진통제 「한 달에」 빠짐(en·es·ja), 담낭 단정 완화(es·ja).
- 10-29 다음 증상 10편(비염·속쓰림·변비·불면·메스꺼움·장염·어지럼·방광염·관절염·숙취) 조건 낱말 대조: ja 넘게→を超えて 12곳, 감별→가능성(어지럼·관절염), 119。 뒤 빈칸, es 불면 어순·비염 단정, zh 불면 3周以上→超过3周. 참고: 방광염 「1년에 세 번 넘게」는 흔한 기준(1년 3번 이상)과 경계가 달라 한국어 원문 확인 거리.
- 10-29 「넘게」 전수: ja 以上→を超えて 23곳(기간). 현욱님 원칙(방광염 결정)대로 지침 문턱은 「이상」: 통풍 1년 두 번 이상(미국류마티스학회 2020), 골밀도 65세 이상 여성·70세 이상 남성(미국 예방서비스 특별위원회 2018).
- 10-29 입술 포진 「6번 넘게」→「6번 이상」(같은 원칙, Leung 2017).
