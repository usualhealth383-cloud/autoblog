# 장부 — 일본어(ja) 원어민 확인·예외

## 숫자 검사 예외
- ui 「파마브롬 (이지엔6 이브 성분)」 → 「パマブロム(月経痛用配合薬の成分)」: 상표(이지엔6 이브)를 빼서 숫자 6이 없어짐.
- 원문의 우리말 수(한 번·두 가지·사흘 등)는 숫자 검사를 맞추려고 한자 수(一・二・三…)로 씀(예: 「二回分」「一日」). 일본어로는 자연스럽지만 표기가 섞여 보이면 원어민 확인.

## 원어민 확인 필요
- 상표 이름 그대로 가리키는 문자열(제품 목록·출처·「Tylenol은 상품 이름이에요」 설명)은 로마자 + 「(韓国の製品)」. 로마자 표기(예: Geborin, Pancol-A, Setopen, Tramol)는 회사 공식 영문 표기와 다를 수 있음.
- 한국 제약사 영문명(Samnam·Sama·Sam-Ik·Daewoo·Dong-A 등)은 추정 표기.
- 「e약은요」 → 「e薬は」 그대로 음역(한국 서비스 이름). 사람 이름 예시 「서아」 → 「さくら」로 바꿈.
- 「911 …」 문자열은 원문(이미 911)대로 둠.
- 연구 요약 조각(「…였다」 등 다체)은 「…だった」로 맞춤 — 앞뒤 조각과 이어 읽어 확인 필요.
- 「건강기능식품」은 일본 제도(機能性表示食品)와 다르므로 문맥에 따라 「健康食品(機能性表示)」/「韓国食品医薬品安全処 健康機能食品」으로 나눔.

## 10-28 영어 검수에서 찾은 조건 낱말 실수를 같은 눈으로 대조(응급 신호 줄)
- 「함께/또는」 범위(담관염·고열과 함께·고열·옆구리 함께)·「번지는 것은 두피 병변」·「지금 응급실」을 바로잡음. es 는 「의식 저하」(somnolencia → 의식 수준 저하)·「처음 겪는 두통」(평생 최악 → 처음 겪는)도.
- 청력·침 삼킴·마비는 이미 맞았음.

- 10-28 응급 신호 전수 자체 점검(285줄): 「감별/descartar」 → 「~일 수 있어요」 꼴, 청력 「안 돌아와요」 → 「돌아오지 않을 수 있어요」, 의식 저하·처짐 낱말 보강. 바꾼 줄은 현욱님 GPT 검수로.
