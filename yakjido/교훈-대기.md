# 공통 교훈 — 대기(yozm-health `docs/memory/shared-lessons.md` 로 옮길 것)

> 그 저장소에 쓸 수 없을 때 여기 적는다(루트 CLAUDE.md). 옮긴 줄은 지운다.

- 10-13 · 박찬 과학 · **외부 AI 검수용 '검수 입구'**: 고정 시계로 앱을 실제로 눌러 며칠 사용한 기록을 만들고(localStorage 떠 두기) → 정적 페이지가 그 기록을 넣으며 날짜를 오늘로 옮김(주 단위 키는 월요일로 맞춤) · 기존 기록 보관/되돌리기 → ChatGPT 에이전트가 빈 앱이 아니라 '쓰던 앱'을 본다. 같은 틀을 다른 앱에도 쓸 수 있다(parkchan-science `app/review.html` · `tools/make_review_fixtures.py` · `tools/review_pack.py` · 의뢰서 `docs/17`).
- 10-13 · 박찬 과학 · **화면 검수는 e2e 가 못 잡는 것을 잡는다**: CSS 클래스 이름 겹침(한 화면 줄이 세로로 깨짐), 로컬 DB 칸 이름 겹침(객체 ↔ 배열로 저장 실패). 새 클래스·칸 이름은 쓰기 전에 grep.
- 10-13 · 박찬 과학 · **검수 지적(사람·AI)은 그대로 믿지 않는다**: 화면 묶음 검수 지적의 약 1/3 은 찍는 방식 때문(고정 탭 바, 영어 날짜 입력, 창마다 다른 상태)이었다. 재현 → 사실 확인 → 반영.
- 10-13 · 박찬 과학 · **할인율·가격은 화면에서 계산해 내림**: 손으로 쓴 '51 % 할인'이 실제 50.3 %였다(표시·광고 부풀림). 미성년자 결제 화면은 숫자 한 곳·자동 결제 없음 명시.
- 10-13 · 박찬 과학 · 원본(교재)은 맞는데 앱으로 옮기는 추출기가 첫 상자·첫 그림·첫 문단만 읽어 '풀 수 없는 문항'이 나가 있었다 → 정답 검수 때 원본이 아니라 **앱에 실린 자료**(bank.json)를 풀게 하고, 옮기기 결함은 빌드 검사로 막는다.
- 10-13 · 박찬 과학 · 여러 에이전트를 동시에 돌릴 때 공용 scratchpad 의 같은 이름 스크립트(shot.py·txt.py)를 서로 덮어씀 → 에이전트마다 `scratchpad/<작업명>/` 하위 폴더를 쓰라고 지시하고, 소단원 파일 되돌리기는 `git checkout` 대신 자기 백업으로
- 10-13 · 박찬 과학 · 여러 갈래로 나눠 쓴 내용은 각자 검사를 다 통과해도 **갈래끼리 값·표기가 어긋난다**(46억/50억 년 · 430만/400만 t · 글리신/글라이신) → 끝에 전체 대조를 한 번 돌리고, 교과서 관행값과 최근 측정값이 다르면 둘 다 적는다
- 10-14 · 박찬 과학 · **과학 오류 대부분은 '조건 없는 단정'**(늘·반드시·모든·~에만·전부): MRI 는 늘 극저온, 세포벽은 식물에만, 세균은 분해자, 생태 피라미드는 언제나 — 각 장 검사는 다 통과한 상태였다 → 단정 문장 목록 도구(`parkchan-science/tools/absolute_audit.py`)로 훑고, 문항마다 '이 문제를 풀려면 무엇을 생각해야 하나'를 한 줄로 쓰게 한다(현욱님 「문제를 위한 문제는 없어야」 · docs/24).
- 10-14 · 박찬 과학 · **문서에 쓴 약속은 서버로 실제로 막는다**: 처리방침에 '동의 전엔 저장 안 함'이라 적어 놓고 서버는 받고 있었다(아동 이용권·알림 토큰). 법 문서 번호를 끼워 넣다 문장이 잘린 채 공개된 일도 → 빌드 관문에 문서 검사(번호·잘림·【확인 필요】)를 넣는다.
- 10-14 · 박찬 과학 · 시간에 기대는 화면 시험(0.24초 움직임 뒤 클래스 확인)은 기계가 바쁠 때 실패한다 — '깜빡이는 실패'로 넘기지 말고 붙는 순간을 기록하는 꼴(MutationObserver)로 고친다.
- 10-14 · 박찬 과학 · **처리방침의 보관 기간은 한 줄마다 파기 코드 한 줄과 시험으로 맞춘다**: 외부 법무 검수에서 '수강 끝 1년'(파기 코드 없음)·'답 달린 글은 익명화해 남김'(실제는 탈퇴 때 연쇄 삭제)·'서버 로그 3개월 통신비밀보호법'(저장 안 함, 대신 Supabase Auth 가 DB 에 로그인 IP 를 기한 없이 쌓고 있었음)이 나왔다 → 보유 기간을 표 하나로 만들고 `purge_old` 와 줄마다 대조. 쓰는 외부 서비스(Supabase Auth 감사 기록 등)가 **DB 안에 스스로 남기는 개인정보**도 찾아 표에 넣는다.
- 10-14 · 박찬 과학 · 원장만 봐야 할 자동 판정(자해 신호 `care`)이 열 단위 권한(grant select)에 들어가 있어 **모든 학생이 남의 글 판정을 API 로 읽을 수 있었다**(화면에만 안 보임) → 민감한 칸은 grant 에서 빼고 원장 함수로만, 화면 표시는 보이는 글에서 앱이 계산. 새 칸을 grant 목록에 넣을 때 '누가 읽어도 되는가'를 묻는다.
