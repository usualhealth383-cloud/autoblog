# 약지도 인계 — 다른 세션이 그대로 이어받기 위한 문서

> 현욱님 결정(2026-09-15): **앱은 약지도 하나로 간다.** 약손은 데이터 원고를 만들고,
> 약지도가 그것을 가져와 앱으로 낸다. 앱을 둘로 유지하면 반드시 갈라진다.
> 이 문서 하나로 저장소를 다시 훑지 않고 시작할 수 있어야 한다.

## 1. 무엇인가
- 약지도 — 증상을 고르면 **무엇을 사고, 어떻게 먹고, 언제 병원에 갈지**를 먼저 알려 주는 앱.
  제일 중요한 사용자는 **어르신**이다. 성분명을 모르셔도 제품 이름으로 닿을 수 있어야 한다.
- 저장소 `usualhealth383-cloud/autoblog`, 브랜치 `claude/medicine-recommendation-app-na6x0m`.
- 폴더 `yakjido/`(원본) → `docs/yakjido/`(배포본, GitHub Pages).
- 아티팩트(미리보기): https://claude.ai/artifact/9hsGKmBcZHpL16LtNoxCnn

## 2. 정본은 JSON — 배포본 HTML 을 손으로 고치지 마라
```
yakjido/app-shell.html          앱 껍데기(화면·로직). 여기를 고친다.
yakjido/content/*.json          내용. drugs / symptoms / classes / sources / supplements / tips / meta …
                                 같은 이름에 .partN.json 을 더하면 합쳐진다(리스트는 이어붙이고 딕셔너리는 덮어씀).
yakjido/art/*.webp              삽화. 파일이 있을 때만 그려진다. 지우면 자리도 사라진다.
python3 yakjido/tools/build.py  → docs/yakjido/index.html (내용을 껍데기에 심는다) + 아이콘·sw.js
```
- 큰 자료(식약처 공공데이터·사전)는 인라인하지 않고 `docs/yakjido/data/*.json` 으로 **지연 로드**한다.
- `docs/yakjido/data/` 는 `.gitignore` 의 `data/` 규칙에 예외를 걸어 두었다. 지우지 말 것.

## 3. 약손 데이터 가져오기
정본: `usualhealth383-cloud/yozm-health` 의 `med/약손_앱/데이터/*.json` (그쪽 인계: `med/약손_앱/인계_0915.md`)
```
git clone --depth 1 https://github.com/usualhealth383-cloud/yozm-health /home/user/yozm-health
# yakjido/tools/yakson/SOURCE.md 의 표대로 6개 파일 복사
python3 yakjido/tools/import_yakson.py   # 성분·제품·질문·영양제 → docs/yakjido/data/
python3 yakjido/tools/import_mix.py      # 「같이 먹어도 되나요」 → mixes.json
python3 yakjido/tools/import_combo.py    # 약지도에 없는 증상만 골라 symptoms.part6.json
python3 yakjido/tools/build.py
```
- 분류(일반·전문)는 **식약처 공공데이터와 대조해 정정**한다. 정정 근거는 `import_yakson.py` 의 `FIX` 에 적어 둔다.
- 약손 원고에 「현욱님 임상 검수 전」이 있으면 `reviewed:false` 로 넘어온다. 임의로 지우지 말 것(§6).

## 4. 시험 — 올리기 전 반드시
```
cd docs/yakjido && python3 -m http.server 8765 &
cd <스크래치패드> && for f in test6 newc ov2 pharm gq step2 uro ach lex hello; do python3 $f.py; done
```
- playwright chromium: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`
- **넘침 검사에서 닫힌 `<details> .bd` 는 빼야 한다** — 크롬이 안 보이는 내용에도 좌표를 준다.
- 가로 스크롤이 정상인 곳(`.scroll-x`, `.tabs`, `.quick`)도 제외한다.
- 대비비(WCAG AA)는 라이트·다크 둘 다 0건이어야 한다. 밝은 배경 위 글자는 `--on-primary`·`--on-alert` 토큰을 쓴다.

## 5. 지키는 것
- **첫 진입에 동의·면책 벽 금지.** 안내는 하되 언제든 건너뛸 수 있어야 한다(`#/hello`).
- 임상 수치는 근거를 확인하고 출처를 단다. 확인 못 하면 **[확인 필요]** 나 「미확인」을 그대로 보인다.
- 근거가 약한 것을 추천 자리에 올리지 않는다. 생약은 사전에서 `근거 제한적` 배지로만 다룬다.
- 경고는 위계를 지킨다 — **빨강은 「병원 가세요」 하나**. 중복·겹침은 노란 톤.
- 어르신 기준: 글자·단추 크게, 잘린 글자 금지, 어절 경계에서 줄이기.
- 사용자 정보는 기기에만(localStorage). 어디로도 보내지 않는다.

## 7. 묻지 말고 이렇게
- 큰 HTML(800 KB)은 Read 로 열지 말고 python 으로 조각만 뽑는다.
- 고칠 때는 `app-shell.html` 을 고치고 build.py 를 돌린다. `docs/` 를 직접 고치면 다음 빌드에 날아간다.
- 확인은 **수치**로(요소 개수·대비비·넘침). 스크린샷은 현욱님께 보여 드릴 때만.
- 커밋 끝에 `Co-Authored-By` 와 `Claude-Session` 줄을 붙인다.
