> 현욱님 결정(2026-09-15): **앱은 약지도 하나로 간다.** 약손은 데이터 원고를 만들고,
> 약지도가 그것을 가져와 앱으로 낸다. 앱을 둘로 유지하면 반드시 갈라진다.
> 이 문서 하나로 저장소를 다시 훑지 않고 시작할 수 있어야 한다.

  제일 중요한 사용자는 **어르신**이다. 성분명을 모르셔도 제품 이름으로 닿을 수 있어야 한다.
- 저장소 `usualhealth383-cloud/autoblog`, 브랜치 `claude/medicine-recommendation-app-na6x0m`.
- 폴더 `yakjido/`(원본) → `docs/yakjido/`(배포본, GitHub Pages).
- 아티팩트(미리보기): https://claude.ai/artifact/9hsGKmBcZHpL16LtNoxCnn

## 2. 정본은 JSON — 배포본 HTML 을 손으로 고치지 마라
```
yakjido/app-shell.html          앱 껍데기(화면·로직). 여기를 고친다.
yakjido/content/*.json          내용. drugs / symptoms / classes / sources / supplements / tips / meta …
                                 같은 이름에 .partN.json 을 더하면 합쳐진다(리스트는 이어붙이고 딕셔너리는 덮어씀).
yakjido/art/*.webp              삽화. 파일이 있을 때만 그려진다. 지우면 자리도 사라진다.
python3 yakjido/tools/build.py  → docs/yakjido/index.html (내용을 껍데기에 심는다) + 아이콘·sw.js
```
- 큰 자료(식약처 공공데이터·사전)는 인라인하지 않고 `docs/yakjido/data/*.json` 으로 **지연 로드**한다.
- `docs/yakjido/data/` 는 `.gitignore` 의 `data/` 규칙에 예외를 걸어 두었다. 지우지 말 것.


  항콜린 이중계산 0 · 이름 검색 8건 — 하나라도 실패하면 종료 코드 1.

- **넘침 검사에서 닫힌 `<details> .bd` 는 빼야 한다** — 크롬이 안 보이는 내용에도 좌표를 준다.
- 가로 스크롤이 정상인 곳(`.scroll-x`, `.tabs`, `.quick`)도 제외한다.
- 대비비(WCAG AA)는 라이트·다크 둘 다 0건이어야 한다. 밝은 배경 위 글자는 `--on-primary`·`--on-alert` 토큰을 쓴다.

## 5. 지키는 것
- **첫 진입에 동의·면책 벽 금지.** 안내는 하되 언제든 건너뛸 수 있어야 한다(`#/hello`).
- 임상 수치는 근거를 확인하고 출처를 단다. 확인 못 하면 **[확인 필요]** 나 「미확인」을 그대로 보인다.
- 근거가 약한 것을 추천 자리에 올리지 않는다. 생약은 사전에서 `근거 제한적` 배지로만 다룬다.
- 경고는 위계를 지킨다 — **빨강은 「병원 가세요」 하나**. 중복·겹침은 노란 톤.
- 어르신 기준: 글자·단추 크게, 잘린 글자 금지, 어절 경계에서 줄이기.
- 사용자 정보는 기기에만(localStorage). 어디로도 보내지 않는다.

## 7. 2026-09-15 밤 이후 — 성분 엔진·병용 판정·디자인 재구성

### 뿌리: 성분 표 (`content/ingredients.json` ← `tools/make_ingredients.py`)
- 손으로 적은 약 96개에만 항콜린 점수가 있어, 내 약통에 담은 처방약은 0점이었다. 그래서 **성분 단위** 표를 두었다.
- 식약처 낱알 자료의 성분명은 염 표기가 앞뒤로 붙는다(염산노르트립틸린 / 아미트리프틸린염산염) → `SALT` 로 벗기고 어근으로 맞춘다.
- 한국 약 이름은 INN 어간을 옮겨 적어 **어미가 곧 계열**(…사르탄=ARB, …프릴=ACEI). `aka` 에 어미를 두면 이름을 모르는 약도 계열까지 잡힌다.
- 긴 어근이 이기면 짧은 쪽은 버린다(부틸스코폴라민 ⊃ 스코폴라민). 2.4만 제품 전수에서 이중계산 0건.
- 항콜린 척도는 **KABS**(한국형). 성분별 점수표 원문이 비공개라 개별 점수는 ACB/ARS 합의를 따르고, 그 사실을 화면에 적었다. 출처 `kabs2019dev·kabs2021ed·kabs2020dem·kabs2024mort`.
- '필요할 때만' 자리의 약은 점수를 절반으로 센다. 용량·기간은 보지 못한다고 화면에 명시.

### 병용 판정 (`content/interactions.json` ← `tools/make_interactions.py`, 화면 `#/together`)
- 규칙 44개: `need`(묶음마다 하나씩, 서로 다른 약) · `count`(같은 계열 n개) · `flags`(내 정보 조건) · `over`(센 규칙이 약한 규칙을 가림).
- 증상 화면 추천 아래 `ixLine` 이 "사기 전에" 한 줄로 알린다. 내 약통과 추천에 **걸친** 것을 먼저.
- 강조는 `**별표**`. `<b>` 는 fmt() 가 이스케이프해 글자로 샌다.
- 아무것도 안 나와도 "안전하다"는 뜻이 아니라는 문장을 화면에 반드시 둔다.

### 이름을 몰라도 담기 (`#/kinds`, `ingredients.json` 의 `quick`)
- 14묶음 44선택지. 담기면 `ME.taking` 에 `cls:bp.arb` 처럼 들어가고 화면에 '대략'으로 표시된다.
- 성분이 하나로 정해지는 선택지(와파린 등)는 `k` 를 줘서 성분 단위 규칙까지 걸린다.

### 디자인 재구성 (현욱님 지적: 글 나열·역동성 없음)
- 그룹별 방 색 `.g-*`(배경 틴트·아이콘에만, 경고색 아님). 증상 아이콘은 `ICON_BY_ID` 로 고유하게.
- 홈: '오늘의 한 장'(`seasonPick`) + 계절 그룹이 위로. 증상 상세: 조건 2열, 신호등 `trafficLight`, 펼침 카드 `xcard`(말풍선·체크리스트·금지·타임라인·Q/A).
- 시그니처: 항콜린 게이지 `achGauge`. 입장 모션 `#view>*{animation:rise}` — reduced-motion 이면 없음.
- 팁은 카드 덱, 약 사전 '전체'는 계열별 3개 + 더 보기. 뒤로 가기 스크롤 복원 `HIST/SCROLL`. 오프라인 띠 `netBar`.

## 8. 2026-09-16 아침 — 내용 보완·한 장 화면·며칠만

- **`#/bag` 제가 먹는 약이에요** — `vBag()`: 약통 번호 목록(큰 글씨) + 「앱이 미리 본 것」(ixRun 결과·같은 성분 겹침·항콜린 점수를 `.show-big` 로) + `shareBag()` 메모 복사. 내 정보·같이 먹어도 되나요 화면에서 들어간다. `tests/run.py` routes 에 넣었다.
- **며칠만** — `ME.short[id]`, `toggleShort()`. `takingItems()` 가 `x.short` 를 붙이고, `achList()` 는 출처를 「내 약통(며칠만)」으로 적어 `prn` 절반 가중이 걸린다. 병용 규칙(ixRun)에는 영향 없음 — 며칠만 먹어도 부딪히는 조합은 부딪힌다.
- **약 상세 차례 줄** — `.jump` + `jumpTab(p)`: 탭 버튼을 click() 하고 `.tabs` 위치로 스크롤(reduced-motion 이면 즉시).
- **출처 칩** — `srcChips` 가 `label.split(' (')[0]` 만 보여 준다. 새 출처를 넣을 때 label 은 「저자 연도, 저널 (설명)」 꼴을 지켜야 칩이 짧게 나온다.
- **FAQ 채우기 규칙** — 증상 JSON `faq:[{q,a}]`, 3문항, a 는 `**굵게**` 가능. 임상 수치는 본문·sources 에 이미 있는 것만. 없는 수치는 쓰지 않는다(지어낸 숫자 0개가 목표).
- **44px 경계** — `.opt-pill` 이 정확히 44.00 이라 웹폰트 교체 순간 43.99 로 떨어져 어두운 테마 검사가 한 번 흔들렸다 → 46px. 탭 타깃은 44 가 아니라 **46 이상**으로 잡는 편이 검사가 안정적이다.
