   - …록시펜·…독시펜: 다리 혈전 신호 → 바로 진료 · 수술·오래 누워 지낼 때 미리 알리기(미국 설명서 72시간 전 중단) · 얼굴 화끈거림·다리 쥐
   - 테리파라타이드: 처음 몇 번 일어설 때 어지럼 → 앉거나 누울 수 있는 곳에서
   - 제안: 이대로 검수 완료 → 「자료 확인 중」 도장 떼기 / 다른 안: 국내 허가(에비스타·비비안트·포스테오) 원문 확인 뒤
2. **흡입기 길잡이에 새로 넣은 칸** — …트로퓸·글리코피로: 매일 같은 시간 · 입마름 · 눈 아픔·흐림·소변 막힘이면 진료 · 녹내장·전립선 비대 알리기
   - 제안: 이대로 검수 완료 / 다른 안: 이프라트로퓸(짧게 듣는 것)도 같은 칸에 넣기
3. **프로프라놀롤 금기** — 교재: 급성 심부전·저혈압·서맥·천식·임신·레이노 증후군. 약지도는 천식·맥 느림·혈압 낮음만(10-13 검수 완료본).
   - 근거 → 국내 인데놀정 허가 원문에 심부전·말초 순환 장애가 금기로 있는지 확인 필요(의약품안전나라 접속 막힘)
   - 제안: 원문에 있으면 「심부전·손발 혈액순환이 나쁜 분(레이노)」 한 줄 더하기 / 다른 안: 지금대로
