# 잉크 판 증상 화면 — 안전 문장 전후 대조표 (11-17 새벽)

바꾼 것은 «보이는 순서와 누르는 방식»뿐이고, 화면에 실린 안전 문장은 하나도 지우거나 고치지 않았다(옛 판은 그대로).

| 자리 | 옛 판(지금) | 잉크 판 | 문장 변화 |
|---|---|---|---|
| 「먼저 확인 — 이 중 하나라도 있나요?」 응급 신호(care.er 최대 4개) | 체크 네모 목록 | 큰 누름 칸(체크하면 빨간 테) | 없음 — 같은 글 |
| 응급 신호 체크 뒤 「약보다 진료가 먼저예요. 지금 119에 전화하거나 응급실로 가세요. 직접 운전하지 마세요. 이럴 때는 약을 사서 버티지 마세요.」 + 119 전화 | 그대로 | 그대로(시험으로 119 단추 확인) | 없음 |
| 「응급 신호가 없다면, 아래 진료가 필요한 경우도 확인해 주세요.」 · 진료가 필요한 경우 접이 | 그대로 | 그대로 | 없음 |
| 진료 신호 체크 뒤 「약보다 진료가 먼저예요. 오늘이나 며칠 안에 병원에 가 보세요.」 | 그대로 | 그대로 | 없음 |
| 「하나도 없어요」 단추 | 없음(숨김) | 새로 — 누르면 답이 열림 | 새 단추 글 하나(안심 문구 아님) |
| 「이렇게 드세요」 답 · 약국 약 카드 · 탭(약국에서 사기·드시는 법·진료실 처방) | 처음부터 보임 | 위험 신호 확인 뒤에 보임(「하나도 없어요」 또는 신호 체크) | 없음 — 같은 글, 보이는 때만 늦춤 |
| 「이럴 땐 병원으로」(triage esc) · 「병원에서는·약국에서는」 접이 · 근거 | 그대로 | 그대로(접이 유지) | 없음 |

자동 시험: `python3 yakjido/tests/ink_safety.py` — 증상 8개 × 두 판.
- 잉크: 확인 전 답 안 보임 · 「하나도 없어요」 뒤 답 보임 · 응급 체크 뒤 119 단추 보임.
- 옛 판: 답이 처음부터 보이고 「하나도 없어요」 단추는 숨어 있음.
