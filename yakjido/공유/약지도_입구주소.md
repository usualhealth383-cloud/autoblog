# 약지도 입구 주소 — 다른 앱에서 약지도 화면으로 바로 보내기 (11-11 · 약지도 세션)

기본 주소 `https://yakjido.medinanum.com/` 뒤에 `#/화면/이름?꼬리` 를 붙인다. 앱(설치판)도 같은 꼬리를 받는다.
처음 오신 분은 약관 동의 화면을 먼저 보고, 동의하면 **그 주소로 그대로 돌아간다**(11-11 실측 — 새 기기 6가지 주소 모두).

## ⛔ 먼저 — `#od` 는 증상 입구가 아니다
`#od` = 「많이 먹었을 때 · 두 번 먹었을 때」(과다 복용) 화면이다. `#od?sym=설사` 를 보내면 **과다 복용 화면이 열린다**(11-11 실측).
아이가 약을 잘못 먹었을 때만 `#/od` 를 쓴다.

## 지금 되는 주소 (11-11 실측)
| 무엇 | 주소 | 보기 |
|---|---|---|
| 증상 화면(약국 약 갈래·먹는 법·병원 갈 때) | `#/symptom/<증상 id>` | `#/symptom/diarrhea` |
| 약 성분 화면 | `#/drug/<약 id>` | `#/drug/loperamide` |
| 상품 이름으로 그 약 열기 | `#/drug/<약 id>?p=<상품명>` | `#/drug/acetaminophen?p=어린이 타이레놀 현탁액` |
| 한글 낱말로 찾기(증상·약 이름 아무거나) | `#/search?q=<낱말>` | `#/search?q=로페라마이드` · `#/search?q=설사` |
| 아이 해열제 용량(몸무게) | `#/kids` | |
| 과다 복용 · 잘못 먹음 | `#/od` | |
| 약 겹침 확인 | `#/together` | |
| 영양제 | `#/supp` | |

- id 는 영어 소문자로 고정이다(바뀌지 않는다). 한글은 `encodeURIComponent` 로 감싼다.
- 모르는 id 는 홈으로 간다(오류 화면 없음). 이름만 알면 `#/search?q=` 가 가장 안전하다.

## 꼬리(어느 앱에서 왔는지) — 11-11 켜짐(작업 가지 · 배포 전)
| 꼬리 | 값 | 약지도가 하는 일 |
|---|---|---|
| `from` | `kids` · `gildongmu` · `gyeote` · `clinicscore` | 맨 위 띠에 「○○에서 오셨어요」와 그 앱으로 돌아가기. `kids` → 아이 기준(부모 몸 조건 빼고 · 그 나이에 안 쓰는 약 빼기 · 어른 용량 칸·처방 조합 숨김 · 「어른 기준으로 보기」로 끔) · `gildongmu` → 항암 중 열 38.0도·혈소판 두 줄을 맨 위에 |
| `age` | 개월 수(숫자) · 또는 `adult` | `kids` 일 때 그 나이(설명서 기준)에 안 쓰는 약을 뺌 · 없으면 12세부터인 약만 뺌 |

- 꼬리는 이 방문(탭) 동안 기억한다(다른 증상 화면으로 옮겨도 띠가 남음 · 실측). 「어른 기준으로 보기」를 누르면 끈다. 서버로 보내지 않는다.
- ⚠️ 배포(main 병합) 전까지 공개 판은 예전 그대로(어른 기준)다. **소아 앱은 배포 소식 뒤에 `#/symptom/...?from=kids&age=` 를 쓴다** — 그 전에는 `#/kids`.
- 꼬리에 이름·병명·수치를 넣지 않는다(주소는 기록에 남는다). 약지도도 꼬리를 서버로 보내지 않는다.
