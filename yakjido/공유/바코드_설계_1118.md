# 약 상자 바코드로 담기 — 설계 (11-18 · 코드는 CSV 받은 뒤)

현욱님 결정(11-18): 심평원 의약품표준코드는 API 가 아니라 **CSV 파일** — 현욱님이 내려받아 두셨고 Main 이 저장소로 옮겨 경로를 알려 준다. 그전에는 설계만.

## 1. 한 줄 흐름 (사용자)
「+ 약 더하기」 → **「상자 바코드로」** → 카메라가 상자 옆 바코드를 비춤 → 0.5초 안에 제품 이름이 뜸 → 「이 약이 맞아요」를 누르면 내 약통에 담김 → 곧바로 겹침 카드(로드맵 3번 「담자마자 겹침」).
- 자동으로 담지 않는다 — 제품 이름·성분·회사를 보여 주고 **사용자가 확인**한 뒤에만.
- 못 찾으면: 「이 상자는 아직 목록에 없어요」 + 「사진으로 담기」·「이름으로 찾기」 두 길(막힘 없이).

## 2. 자료 (빌드에서 한 번, 앱은 읽기만)
| 단계 | 무엇 | 메모 |
|---|---|---|
| 원본 | 심평원 약가마스터 «의약품표준코드» CSV(표준코드 13자리 · 제품코드 9자리 · 제품명 · 업체 · 규격 · 기준일) | 열 이름은 파일을 보고 확정 [파일 오면 확인] |
| 이음 | 제품코드(9자리) ↔ 식약처 허가 목록 `EDI_CODE` → 우리 품목(`pub:<품목기준코드>`) | 허가 목록은 이미 받는 자료(fetch_mfds) |
| 결과 | `docs/yakjido/data/barcode/<업체 4자리>.json` — `{ "8806xxxxxxxxx": ["<품목기준코드>", "제품명"] }` | 업체별로 쪼개 그 상자에 필요한 조각 하나만 받는다(첫 화면 무게 0) |
| 기준일 | `data/barcode/_about.json` 에 CSV 기준일·줄 수·이어진 수 | 화면 「자세히」에 「심평원 표준코드 2026-08-31 기준」 |
- 도구: `yakjido/tools/barcode_build.py <CSV 경로>` (빌드 때 한 번). 원본 CSV 는 저장소에 두되 앱 묶음(docs)에는 넣지 않는다.
- 한계(정직하게): 약가마스터는 **보험 등재 제품** 위주라 비급여 일반약 상자(감기약·진통제 일부)는 빠질 수 있다 → 못 찾으면 사진·이름 길로. 이어진 비율을 빌드 때 세어 보고 `_about.json` 에 남긴다.

## 3. 바코드 읽기
| 어디 | 방법 | 메모 |
|---|---|---|
| 설치 앱(안드로이드) | 기기 안 바코드 읽기 플러그인(EAN-13) | 사진은 저장·전송하지 않음 — 숫자 13자리만 |
| 웹(크롬 안드로이드 등) | 브라우저 내장 `BarcodeDetector`(ean_13) | 없으면(아이폰 사파리 등) 숫자 13자리 직접 넣기 칸 |
| 공통 | 13자리 + **검증 숫자(GS1 마지막 자리) 확인** · 880 으로 시작하는지 | 틀리면 「다시 비춰 주세요」 |
- 카메라 권한은 「상자 바코드로」를 누를 때만 묻는다. 화면 이탈 시 카메라 바로 끔.

## 4. 화면 (정리 원칙 11-18 그대로)
- 「+ 약 더하기」 시트에 길 셋을 같은 모양 줄로: **상자 바코드로 · 약봉투·처방전 사진으로 · 이름으로 찾기**.
- 찾은 카드: 큰 제품 이름 1줄 · 성분 한 줄 · 「이 약이 맞아요」 큰 단추 1개 · 「아니에요」 글 단추. 출처·기준일은 「자세히 ›」 안.
- 가족 프로필이면 「어머니 약통에 담을게요」처럼 누구 약통인지 단추 글에.

## 5. 시험(코드 때 함께)
- 검증 숫자: 맞는 13자리 / 한 자리 틀린 13자리 / 12자리 → 각각 통과·거절·거절.
- 조각 받기: 업체 4자리로 그 조각만 받는지(다른 조각 0).
- 못 찾음: 목록 밖 번호 → 사진·이름 두 길이 보이고 막힘 없음.
- 담기 전 확인: 「이 약이 맞아요」 없이 약통에 들어가는 길 0.
- 첫 화면 무게: index.html 증가 0(바코드 코드는 srv.js·조각 파일에).

## 6. 기다리는 것
- CSV 경로(Main) → 열 이름 확인 → `barcode_build.py` · 이어진 비율 보고 → 화면 구현 → 사진 2장.
