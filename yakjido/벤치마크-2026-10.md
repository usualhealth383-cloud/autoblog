# 국내외 약·증상 서비스 벤치마크 — 2026-10-01

현욱님 지시: 「사이트를 통해 여러 곳을 분석해보고 좋은 점을 잘 가지고 와서 앱을 완전히 보완」.
네 갈래로 실제 접속해 읽었다(접속 날짜 2026-10-01). **Drugs.com·Mayo Clinic은 접속 차단(403)** 이라 확인하지 못함.

|---|---|

## 이미 우리가 앞선 것 (비교해 보니 있음)
- 증상 화면의 **3단계 색 카드**(약국 / 병원 / 119) — NHS 4단계와 같은 구조, 「며칠 지나도」 숫자 기준 포함
- 필요할 때 먹는 약의 **「다음은 몇 시부터 · 오늘 몇 번」** — 해외 앱(DoseAlert)에만 있던 것, 우리는 하루 상한까지 봄
- **같은 성분 두 번**(감기약 + 타이레놀) 경고 — MedlinePlus·healthdirect는 문장으로만, 우리는 약통으로 실제 계산
- 부작용 기록 + 피해구제 안내, 남은 약 개수, 파일로 옮기기, 종이로 뽑기, 어린이 몸무게 용량 + 약병 설명서 기준 줄

## 이번에 넣은 것 (2026-10-01)
1. 약 화면 「**깜빡 잊었을 때 · 너무 많이 드셨을 때**」 두 칸 — NHS·MedlinePlus·Patient.info 공통, 우리만 없던 것. 근거: NHS 중독·파라세타몰(토하게 하지 말 것·포장 가져가기·증상은 몇 시간~며칠 뒤). 약마다 다르면 `d.missed`/`d.overdose` 로 덮어쓴다.
2. 증상 카드에 「**어디로**」 — 약국 카드: e-gen 문 연 약국·휴일지킴이약국 / 병원 카드(아이일 때): 달빛어린이병원·아이안심톡 / 119 카드: 「직접 운전하지 마세요·약 챙기기」 + 응급실 찾기 + 내 약 목록 보이기. (NHS 「Find a pharmacy」, healthdirect Service Finder 자리)
3. 부작용 화면: 식약처 **온라인 이상사례 보고(일반인)**·**부작용 대처법** 링크
4. 내 약통: 심평원 **「내가 먹는 약! 한눈에」·「DUR 국민 체험관」** 링크(우리 앱은 그 기록을 가져오지 않음 — 서버 수집 금지 원칙 유지)
5. 달력 알림에 **30분 뒤 한 번 더**(애플 건강 방식) · 늦어진 복용엔 «드셨는지 기억이 안 나요» 안내
6. 약 화면 근거 칸에 「**식약처 허가사항 변경명령과 대조한 날**」(NHS의 «검토일» 자리) — `meta.labelCheck`
7. **회수 공지** — 식약처 회수·폐기 목록 912건 중 사용기한이 남은 제조번호이면서 앱에 나오는 제품 64개(예: 마데카솔케어연고 일부 제조번호, 수면유도제 카메드정·디카엠정 불순물)

## 쓰면 안 되는 것·주의
- 약학정보원 자료는 **복제·상업 이용 금지 약관** — 링크만(사진은 현욱님 허락 범위 안에서만). 질병관리청·한국의약품안전관리원 글은 공공누리 4유형(변경 금지·비상업) → 링크만.
- 공공데이터포털 API(e약은요·낱알식별·DUR)는 «이용허락범위 제한 없음».
- 1339는 2012년 119로 합쳐짐 — 앱에 표시하지 않음(자동 링크 정규식에만 남아 있음).
- e-gen(www.e-gen.or.kr)은 서버 인증서 묶음이 불완전해 일부 환경에서 HTTPS 경고가 날 수 있음 — 실제 휴대폰에서 한 번 확인 필요(**미검증**).
