# 로컬 세션 작업 지시서 — 약지도

이 문서는 **인터넷이 열려 있는 로컬(제작 PC) 세션**이 할 일만 모은 것입니다.
클라우드 세션은 바깥으로 나가는 길이 막혀 있어 아래 일들을 끝낼 수 없습니다.

> 먼저 읽을 것: `인계.md`(설계 규칙 전부) · `의사-피드백.md`(현욱님 지시 기록)
> 저장소: `usualhealth383-cloud/autoblog` · 작업 가지: `claude/medicine-recommendation-app-na6x0m`

## 0. 클라우드 세션에서 막힌 것 (직접 확인함)

| 주소 | 결과 |
|---|---|
| `nedrug.mfds.go.kr` | `connect_rejected` — 식약처 자료·제품 사진을 새로 못 받음 |
| `www.health.kr` | `EGRESS_BLOCKED` — 약학정보원 링크 형식을 확인 못 함 |
| `law.go.kr` · `nih.gov` | 차단 |
| PubMed 도구 | **됨** (문헌 확인은 클라우드에서 계속 합니다) |
| 웹 검색 | 됨 (다만 2차 자료라 임상 수치는 그대로 쓰지 않습니다) |

그래서 **자료를 받아 오는 일**과 **실기기 확인**만 로컬 몫입니다.
내용(임상 문장·계획·설계)은 클라우드에서 계속 만듭니다 — 두 세션이 같은 파일을 동시에 고치지 않도록 아래 규칙을 지켜 주세요.

## A. 제품 «상자» 사진 받아 붙이기 — 가장 급합니다

**무엇이 문제인가.** 지금 앱이 쓰는 사진은 「의약품 낱알식별 정보」 하나뿐입니다.
그 자료에는 **알약만** 들어 있어서(일반 5,660건, 전부 사진 있음), **볼타렌 에멀겔·케토톱·아시클로버 크림·질정·시럽은 사진이 아예 없습니다.**
현재 붙은 사진은 82건뿐이고, 나머지는 빈칸입니다.

**받을 것.** 식약처 「의약품 제품 허가정보」 — 제품 상자 사진 칸이 있습니다.
- 벌크 CSV: `nedrug.mfds.go.kr` → 의약품등 정보 → **공공데이터 공개** → 「의약품 제품 허가정보」
  (앞서 e약은요·낱알식별 CSV 를 받은 그 자리입니다)
- 또는 OpenAPI: `data.go.kr/data/15095677/openapi.do` (인증키 무료)

**할 일**
```bash
# 1) 컬럼 이름부터 확인 — 자료마다 다릅니다
python3 yakjido/tools/import_product_images.py <받은파일.csv> --peek

# 2) 이미지 칸이 있으면 그대로 붙입니다
python3 yakjido/tools/import_product_images.py <받은파일.csv>

# 3) 배포본 다시 만들고 검사
python3 yakjido/tools/build.py
python3 yakjido/tests/data.py
python3 yakjido/tests/run.py
```
도구가 **제형이 같은 것끼리만** 붙입니다(로션 자리에 알약 사진이 들어가던 사고가 있었습니다).
낱알 사진이 이미 있는 제품은 건드리지 않습니다.

**결과 보고할 것**: 「몇 건 → 몇 건」, 그리고 `--peek` 이 찍어 준 컬럼 목록.
이미지 칸이 없으면 **다른 자료가 필요하다는 뜻**이니 컬럼 목록만 보내 주세요.

**저작권** — 약학정보원(health.kr) 사진은 공공누리가 아닙니다. **확인 없이 쓰지 마세요.**
지금 쓰는 낱알 사진은 식약처 공공데이터로 받은 것이고 출처를 화면에 표시하고 있습니다.

## B. 약학정보원 링크가 약 이름을 싣고 가게

지금은 약 화면의 「약학정보원」 링크가 **검색 첫 화면**으로만 갑니다.
`health.kr` 접속이 막혀 있어 검색어를 주소로 넘기는 형식을 확인하지 못했습니다.

**할 일**: PC 에서 약학정보원에 약 하나(예: 파미딘정)를 검색하고 **주소창을 그대로 복사**해 주세요.
형식만 알면 `app-shell.html` 의 `prodLinks()` 한 줄이면 끝납니다.

## C-0. 사진 읽기 서버 배포 (Gemini) — 카메라 정확도

**카메라 촬영과 폰 안에서 글자 읽기는 이미 들어 있습니다.** 서버 없이도 동작합니다.
다만 약봉투처럼 글자가 작고 빽빽한 사진은 폰 안 OCR 만으로는 한계가 있어서,
`yakjido/server/worker.js`(Gemini) 를 배포하면 정확도가 크게 올라갑니다.

```cmd
yakjido\server\deploy.cmd
wrangler secret put GEMINI_API_KEY
```
배포 뒤 앱의 **내 정보 → 사진 서버**에 주소를 붙여 넣으면 됩니다.
**비용**: Gemini 무료 등급 안에서 쓰는 것이 목표입니다. 유료 등급으로 넘어갈 상황이면 먼저 보고하세요.
**OpenAI·gpt-image-1 은 쓰지 않습니다.**

## C. 날씨 서버 배포 (공공데이터포털 인증키)

지금 홈의 날씨는 Open-Meteo 로 동작합니다. 기상청 실황·에어코리아 미세먼지로 바꾸려면:

```cmd
yakjido\server\deploy.cmd
wrangler secret put DATA_GO_KR_KEY
```
**인증키는 절대 저장소에 넣지 마세요.** Cloudflare Worker 비밀값으로만 둡니다.

## 두 세션이 부딪히지 않게

**로컬 세션이 만지는 파일** — 이것만 고치고 커밋하세요.
```
docs/yakjido/data/*          (받아 온 공공데이터)
yakjido/content/productImages.json
yakjido/tools/import_*.py    (받아 오는 도구)
yakjido/server/*             (날씨 워커)
```
**클라우드 세션이 만지는 파일** — 건드리지 마세요.
```
yakjido/app-shell.html
yakjido/content/drugs*.json · symptoms*.json · classes*.json · sources*.json
yakjido/*.md                 (인계·검수·피드백 문서)
```
같은 가지에 올리기 전에 반드시 `git pull --rebase origin claude/medicine-recommendation-app-na6x0m`.

**끝내기 전에 반드시**
```bash
python3 yakjido/tools/build.py      # 배포본 다시 만들기
python3 yakjido/tests/data.py       # 자료 고리 (1초)
python3 yakjido/tests/run.py        # 화면 233개 (4~6분)
```
셋 다 통과하지 않으면 올리지 마세요.

## 절대 하지 말 것

- **autoblog 자동발행을 켜지 마세요.** 정지 상태이고, 현욱님의 명시적 지시 없이는 재개 금지입니다.
- OpenAI 유료 호출·gpt-image-1 금지. 이미지가 필요하면 Gemini 나노바나나.
- 유료 API·구독이 필요하면 **쓰기 전에** 예상 비용부터 보고.
- 인증키·비밀번호를 파일에 적지 마세요. 화면 캡처에 찍힌 키도 옮겨 적지 마세요.
- 사용자 기록(`yakjido.me.v1`)은 기기에만 둡니다. 서버로 보내는 코드를 넣지 마세요.
- 완성된 화면을 갈아엎지 마세요. 바꿀 일이 있으면 새로 만들고 비교할 수 있게 두세요.
