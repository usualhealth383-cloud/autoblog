# 약지도 — 안드로이드 앱 (Capacitor)

`docs/yakjido/`(웹 배포본)을 그대로 감싼 안드로이드 앱입니다. 웹과 다른 점은 **알림**입니다.

| | 웹(설치형 웹앱·아티팩트) | 안드로이드 앱 |
|---|---|---|
| 앱을 닫았을 때 복용 알림 | 안 울림(달력 파일로 보완) | **울림** — 휴대폰 알람으로 걸어 둔다 |
| 휴대폰을 껐다 켠 뒤 | — | 다시 걸림(재부팅 복구) |
| 알림의 단추 | 먹었어요 · 열기 | **먹었어요 · 10분 뒤 다시** |
| 30분 뒤 「아직 안 드셨어요」 | 앱이 열려 있을 때만 | 앞으로 7일치를 미리 걸고, 먹었어요를 누르면 그날 것을 지움 |
| 약 떨어지기 전 | 화면에만 표시 | 3일치·오늘 치만 남는 날 아침 9시 알림 |
| 혈압 재기 | — | 수첩에서 켜면 매일 아침 7:30·저녁 9:00 |
| 진료 예약 | 화면·홈에 표시 | 전날 저녁 7시·2시간 전 알림 |
| 인터넷 없이 | 받아 둔 만큼 | 자료 전부 앱 안에 있음 |

| 항목 | 값 |
|---|---|
| 앱 ID | 스토어판 `app.yakjido` (2026-10-13 메디나눔 공통 꼴로 바꿈 — 그 전 시험판 `kr.yakjido.app` 은 다른 앱으로 남으니 지우고 새로 설치) · **시험판(디버그) `app.yakjido.test`, 이름 「약지도 시험판」**(10-13 — 공개 시험 키로 서명한 앱이 스토어판을 덮어쓸 수 없게 따로 깔림) |
| 버전 | 사용자에게 보이는 `1.0.0`(package.json 과 같게) · 번호는 빌드 번호×10+다시 돌린 횟수(같은 실행을 다시 돌려도 겹치지 않게) |
| 알림 부품 고침 | `npm install`·`npm ci` 뒤 `tools/patch-local-notifications.js` 가 매일 반복 알림의 다음 날 예약을 폰을 깨우는 꼴로 바꾼다(원래는 도즈에서 늦게 울림). 플러그인 판이 바뀌어 고칠 줄을 못 찾으면 설치를 멈춘다 |
| 위치 | 대략 위치만 — `MainActivity` 가 웹 위치 요청에 ACCESS_COARSE_LOCATION 만 묻는다(Capacitor 기본은 정밀 위치도 같이 물어 안드로이드 11 이하에서 늘 거절됐음) |
| 웹 소스 | `www/` ← `docs/yakjido/` 복사본 (`npm run web`, 서비스워커·매니페스트와, 앱이 읽지 않는 중간 자료 `kpic-guide.json`·`kpic-extra.json` 20 MB 는 뺌 — 제품 화면은 `data/kg/` 조각만 읽는다) |
| 아이콘·스플래시·상태바 아이콘 | `python3 yakjido/tools/make_native_icons.py` 가 **정본 `art/icon-1024.png`** 에서 만든다 |
| 알림 코드 | `app-shell.html` 의 `nativeArm()` — 웹에서는 `NATIVE` 가 거짓이라 건너뛴다 |
| 검사 | `tests/run.py` 의 「앱 알람」 — 가짜 휴대폰 알람 장치로 무엇을 거는지 본다 |

## 자동 빌드 (PC 설치 없음)

약지도 코드가 이 브랜치나 `main` 에 올라가면 **Actions → `yakjido-apk`** 가 저절로 돕니다(5~8분).
실행 화면 아래 **Artifacts → `yakjido-apk`** 의 `yakjido-debug.apk` 를 폰에 옮겨 설치합니다
(설정 → 출처를 알 수 없는 앱 허용).

- 시험용 서명 키(`android/debug.keystore`)를 저장소에 고정해 두었습니다. 새 시험판을 옛 시험판 위에 그대로 덮어 설치할 수 있게 하려는 것입니다. **시험 배포 전용**이고, 스토어 배포본에는 쓰지 않습니다. 키가 공개라서 시험판은 패키지를 `app.yakjido.test` 로 따로 둡니다 — 이 키로 만든 앱은 스토어판(`app.yakjido`) 위에 깔릴 수 없습니다.
- 스토어 제출용(서명본)은 저장소 **Settings → Secrets** 에 아래 4개를 넣어 두면 같은 실행에서 `.apk`·`.aab` 가 함께 나옵니다.

| Secret | 값 |
|---|---|
| `YAKJIDO_KEYSTORE_B64` | 서명 키 파일을 base64 로: `base64 -w0 release.keystore` |
| `YAKJIDO_KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `YAKJIDO_KEY_ALIAS` | 키 별칭 |
| `YAKJIDO_KEY_PASSWORD` | 키 비밀번호 |

서명 키는 처음 한 번 만들고 **잃어버리면 안 됩니다** — 스토어 업데이트마다 같은 키가 필요합니다.

## 앱 내용을 고쳤을 때
```
cd yakjido/app-native
npm install
npm run sync      # 웹 다시 빌드 → www 갱신 → 안드로이드에 복사
```
그 뒤 자동 빌드가 돌거나 Android Studio 에서 Build → Build APK(s).

## 첫 실행에서 사용자가 보게 되는 것
- 알림 권한은 **처음 켜자마자 묻지 않습니다.** 복용 알림 화면의 「휴대폰 알림 → 켜기」를 누를 때 묻습니다.
- 안드로이드 12 이상에서 「알람 및 리마인더」 권한이 꺼져 있으면 휴대폰이 몇 분 늦게 울릴 수 있어, 그때만 「정확한 시각에 울리기 → 허용」 단추가 보입니다. 설정 화면을 억지로 띄우지 않습니다.

## 아직 안 된 것
- 아이폰(iOS) 빌드 — 맥과 애플 개발자 계정(연 12만 원 안팎 [확인 필요])이 필요합니다.
- 스토어 등록 — 서명 키·개인정보처리방침 주소·사업자 정보가 정해진 뒤.
