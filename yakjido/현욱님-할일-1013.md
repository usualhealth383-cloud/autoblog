## ② E1 · 계정 메일 발송사 연결 — Resend (15분, 다섯 앱 공통)
**왜:** Supabase 기본 메일은 시간당 몇 통뿐이라, 이대로면 사람들이 가입 확인·비밀번호 다시 정하기 메일을 못 받습니다.
**비용:** Resend 무료 등급 = 월 3,000통 · 하루 100통(2026 여러 출처 일치 — 가입 때 [요금 쪽](https://resend.com/pricing)에서 한 번 확인). 넘으면 월 20달러부터라, 그때 미리 말씀드립니다.

1. **가입** — [resend.com](https://resend.com) → Sign up(구글 계정 usualhealth383@gmail.com 으로 가능)
2. **도메인 연결** — 왼쪽 **Domains** → **Add Domain** → `medinanum.com` 입력. 지역 고르는 칸이 있으면 가까운 곳(도쿄 등)
   - 다음 쪽에 DNS 줄(DKIM·SPF 등)이 나옵니다. **「Cloudflare 로 자동 설정」 단추가 있으면 그걸 누르세요.** 없으면 Cloudflare → medinanum.com → **DNS** → Add record 로 화면에 나온 줄을 그대로 하나씩 넣기(Proxy 는 회색 구름 = DNS only).
   - 지금 쓰는 메일 받기(Email Routing)와는 겹치지 않습니다(Resend 는 `send.` 같은 하위 이름에 줄을 답니다).
   - 몇 분 뒤 Resend 에서 **Verified** 가 뜨면 다음으로.
3. **API 키** — 왼쪽 **API Keys** → Create API Key → 이름 `supabase-auth`, 권한 **Sending access**, 도메인 `medinanum.com` → 만들어진 `re_…` 키를 **복사만**(대화에 붙여 넣지 말기)
4. **Supabase 에 넣기** — [supabase.com/dashboard](https://supabase.com/dashboard) (parkhy177 계정) → **gildongmu** 프로젝트 → **Authentication** → **Emails**(또는 Settings) → **SMTP Settings** → **Enable custom SMTP** 켜기
   | 칸 | 넣을 것 |
   |---|---|
   | Sender email | `no-reply@medinanum.com` |
   | Sender name | `메디나눔` |
   | Host | `smtp.resend.com` |
   | Port | `465` |
   | Username | `resend` |
   | Password | 3번에서 복사한 키 |
   → **Save**
5. **보내기 한도** — Authentication → **Rate Limits** → 시간당 메일 수를 `30` 정도로(Resend 하루 100통 안)
6. **E2 메일 문구** — Authentication → **Email Templates** → 「Confirm signup」·「Reset password」 제목·본문을 `출시-체크리스트.md` E2 의 메디나눔 공통 문구로 바꾸기(앱 이름 없이)
7. 「했어」 → 제가 순서를 드리면 현욱님 메일로 **비밀번호 다시 정하기**를 웹·설치 앱에서 한 번씩 해 봅니다(메일이 오는지, 링크가 yakjido.medinanum.com 으로 열리는지).
- 근거: Resend 공식 [Supabase 연결 안내](https://resend.com/blog/how-to-configure-supabase-to-send-emails-from-your-domain)

## ③ A3 · 구글 플레이 «조직» 계정 (메디나눔) — 며칠~한 달

2. **영문 사업자등록증명** — 홈택스에서 발급. 여기 적힌 영문 상호·주소를 그대로 씁니다.
3. **D-U-N-S 번호 — 직접, 비용 없이** 신청: Dun & Bradstreet(D&B) 공식 신청 쪽에서. ⚠️ 30만~50만 원 받는 «대행» 광고가 많지만 필요 없습니다. 영문 정보는 2번과 똑같이, 전화번호는 +82. **최대 30일** 걸릴 수 있어요.

6. 계정이 열리면 「열렸어」 → 앱 만들기·스토어 문안(`store/listing.md`)·설문 답은 제가 칸별로 붙여 넣을 글을 드립니다.

## ④ B1·B2 · 앱 서명 키 (PC 10분, 한 번만)
**왜:** 스토어에 올리는 파일은 현욱님만 가진 키로 서명합니다. **이 키를 잃으면 앱을 다시는 업데이트할 수 없습니다** — 두 곳에 보관하세요.

1. **키 만들기** — 윈도우 PC 에서 PowerShell 열기(시작 → PowerShell). Android Studio 가 깔려 있으면 keytool 이 아래 경로에 있어요:
   ```powershell
   cd $HOME\Documents
   & "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -keystore yakjido-release.keystore -alias yakjido -keyalg RSA -keysize 2048 -validity 10000
   ```
   - 비밀번호를 두 번 물어요(키스토어 비밀번호). 이름·조직 칸은 `Minwook Park` / `Medinanum` / `Seoul` / `KR` 정도로.
   - 끝에 키 비밀번호를 따로 물으면 같은 것을 써도 됩니다.
   - Android Studio 가 없으면 「keytool 없음」이라고만 알려 주세요 → 다른 방법을 드립니다.
2. **보관** — `Documents\yakjido-release.keystore` 파일을 **USB 와 구글 드라이브 두 곳**에, 비밀번호는 비밀번호 관리자에.
3. **GitHub 에 넣기(4칸)** — 키 파일을 글자로 바꿔 클립보드에 복사:
   ```powershell
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("$HOME\Documents\yakjido-release.keystore")) | Set-Clipboard
   ```
   그다음 [저장소 Secrets](https://github.com/usualhealth383-cloud/autoblog/settings/secrets/actions) → **New repository secret** 를 네 번:
   | Name | Secret |
   |---|---|
   | `YAKJIDO_KEYSTORE_B64` | 붙여 넣기(Ctrl+V — 방금 복사한 긴 글자) |
   | `YAKJIDO_KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
   | `YAKJIDO_KEY_ALIAS` | `yakjido` |
   | `YAKJIDO_KEY_PASSWORD` | 키 비밀번호 |
4. 「넣었어」 → 제가 빌드를 돌려 스토어용 `yakjido-release.aab` 가 만들어지는지 확인합니다(키 값은 저도 볼 수 없어요).
