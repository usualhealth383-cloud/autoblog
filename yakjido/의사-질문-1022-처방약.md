# 처방약 길잡이 — 현욱님 확인 여섯 가지 (2026-10-22)

`yakjido/rxguide.json` · 화면 `#/rx/bp` `#/rx/dm` `#/rx/chol` `#/rx/thy` `#/rx/mind` — 확인 전까지 화면 머리에 「의사 확인 중」. 확인되면 `rxguide.json` 에 `"reviewed": true`.

1. 콜레스테롤 「간 수치」 칸의 사례 문장 — 「로수바스타틴 복합제를 먹다가 피타바스타틴으로 줄였는데도 간 수치가 올라 다시 약을 바꾼 경우도 있어요」(현욱님 말씀을 이름 없이 옮김). 이대로 둘까요?
2. 설포닐우레아 — 「저혈당이 가장 흔한 계열 · 진료에서 저혈당이 적은 약으로 바꾸기도」. 표현 괜찮을까요?
3. …글리플로진 — 「수술·큰 검사 전이나 못 먹는 날에는 며칠 쉬기도 해요 — 의사가 정해요」(미국 허가: 수술 최소 3일 전 중단 고려). 날짜를 적지 않고 「의사가 정해요」로 둔 것 괜찮을까요?
4. 혈압 응급 — 「180/110 mmHg 넘게 + 심한 두통·가슴 통증·숨참·마비·말 어눌 → 바로 119」, 증상 없이 숫자만 높을 때는 따로 적지 않았어요. 「증상 없으면 쉬고 다시 재고 오늘 진료」 한 줄을 더할까요?
5. 레보티록신 깜빡 — 「생각나면 바로, 다음 먹을 때가 가까우면 건너뛰기 · 하루 빠져도 크게 흔들리지 않음」. 진료실에서 「다음 날 두 알」로 안내하시나요?
6. 출처 — 처방약은 식약처 원문을 이 컨테이너에서 열 수 없어 미국 식품의약국 허가사항(같은 성분)과 학회 지침으로 달았어요. 국내 허가와 다른 곳이 있으면 알려 주세요.
