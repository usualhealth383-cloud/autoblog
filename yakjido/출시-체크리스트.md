### B. PC에서 5분씩
- [ ] **B1. 서명 키 만들기** (한 번만, 잃어버리면 안 됨 — 스토어 업데이트마다 같은 키가 필요)
  ```
  keytool -genkeypair -v -keystore yakjido-release.keystore -alias yakjido -keyalg RSA -keysize 2048 -validity 10000
  ```
  비밀번호 2개(키스토어·키)를 정하고 **비밀번호 관리자에** 적어 두세요. 파일은 USB·클라우드 두 곳에 보관.
- [ ] **B2. GitHub Secrets 4개** — 저장소 Settings → Secrets and variables → Actions → New repository secret
  | 이름 | 값 |
  |---|---|
  | `YAKJIDO_KEYSTORE_B64` | `base64 -w0 yakjido-release.keystore` 의 출력(윈도우: `certutil -encode` 뒤 머리·꼬리 줄 제거) |
  | `YAKJIDO_KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
  | `YAKJIDO_KEY_ALIAS` | `yakjido` |
  | `YAKJIDO_KEY_PASSWORD` | 키 비밀번호 |
  넣으면 다음 빌드부터 Actions 결과물에 `yakjido-release.aab`(스토어용)가 같이 나옵니다.
- [ ] **B3. Supabase 공유 함수** — `share` 함수 다시 배포(이미 하신 것 같다고 하셨음) 뒤 저에게 「배포됨」 한마디. 제가 `expired` 응답을 확인하고 `meta.share.fn` 을 채웁니다.
- [ ] **B4. Supabase 비밀 키 돌리기** — 대화에 붙여 넣으셨던 secret 키는 Project Settings → API Keys 에서 **새로 만들고 옛것 폐기**.
- [ ] **B5. (선택) 사진 서버** — `yakjido/server/worker.js` 머리말 5줄대로 wrangler 배포 + Gemini 키. 없어도 출시 가능(이름으로 찾기가 주 경로).
